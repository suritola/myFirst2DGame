description: 기능을 만들기 전이나 후에 놓치기 쉬운 예외 상황, 빈 상태, 오류 상태를 나열한다. 사용 예 /edge-cases 스킨 상점 구매
argument-hint: <기능>
---

기능: $ARGUMENTS

관련 코드를 읽고, 정상 흐름에서 벗어나는 경우를 나열한다.

- 빈 상태: 포인트 0, 보유 스킨 없음, 도감 미해금, 첫 실행(세이브 없음)
- 경계값: 최대 레벨, 체력 0 직전, 동시 처치, 뽑을 카드가 모자랄 때
- 타이밍: 일시정지·레벨업 창·게임 오버가 겹칠 때, 씬 전환 중, 빠른 연타
- 입력: 키보드·마우스·패드, 해상도·창 크기 변경
- 저장: 이전 버전 세이브, 값이 깨졌을 때
- 연출: 이펙트·소리가 겹치거나 남는 경우

항목마다 지금 코드가 처리하는지(`파일:줄`), 처리하지 않으면 무슨 일이 생기는지 적는다. 코드는 수정하지 않는다.
