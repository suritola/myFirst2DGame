이 Unity 프로젝트(Soul Saver)의 전체 구조를 한국어로 설명한다.

1. `Assets/` 아래 폴더(Scripts, Prefabs, Resources, Editor 등)의 역할을 정리한다.
2. `Assets/Scripts/`의 스크립트를 기능별로 묶는다 (플레이어·무기, 적·보스, 레벨업 카드·영혼 트리, UI·메뉴, 스킨·상점, 도감, 저장 등).
3. 게임 한 판이 흘러가는 순서대로 핵심 클래스가 서로 어떻게 부르는지 설명한다 (메인 메뉴 → 게임 시작 → 전투 → 레벨업 → 종료·보상).
4. `tools/`(release.ps1, 도트 생성 스크립트 등)와 `docs/`의 용도를 짧게 덧붙인다.

파일을 하나하나 다 열지 말고 클래스 이름, public 멤버, 호출 관계 위주로 훑는다. $ARGUMENTS 가 있으면 그 부분에 집중한다.
