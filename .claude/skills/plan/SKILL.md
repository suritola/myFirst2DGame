하려는 변경: $ARGUMENTS

**이 스킬에서는 파일을 수정하지 않는다.**

1. 관련 코드를 읽고 지금 구조를 파악한다.
2. 바꿀 파일 목록과 파일마다 무엇을 바꿀지 적는다. 스크립트뿐 아니라 프리팹·씬, 저장 데이터, 도감·설정 UI, 패치노트처럼 빠뜨리기 쉬운 곳도 포함한다.
3. 방법이 여러 개면 추천안 하나와 그 이유를 준다.
4. 위험 요소(세이브 호환, 밸런스, 에디터 전용 코드 금지 규칙)와 확인 방법을 적는다.
5. 작업 규모를 "작음 / 보통 / 큼"으로 판정한다.

사용자가 계획을 승인하면 그때 구현한다.
