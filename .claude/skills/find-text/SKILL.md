argument-hint: <지금 문구> → <바꿀 문구>

요청: $ARGUMENTS

1. 스크립트(.cs)와 직렬화된 텍스트(.prefab, .unity, .asset 안의 문자열)에서 해당 문구를 찾는다. 띄어쓰기나 조사만 다른 변형도 찾는다.
2. 찾은 곳을 앞뒤 맥락과 함께 목록으로 먼저 보여 준다.
3. 식별자, 저장 키, 파일 이름, 지난 패치노트(`docs/patch-notes/`), 커밋 기록은 건드리지 않는다.
4. 화면에 보이는 문구만 바꾸고, 글자 수가 늘어 UI 칸을 넘칠 만한 곳을 알려 준다.
5. 바꾼 파일을 모두 보고하고 AGENT.md 규칙대로 커밋한다.
