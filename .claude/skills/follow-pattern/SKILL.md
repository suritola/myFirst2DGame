name: follow-pattern
description: 이미 있는 구현을 참고해서 같은 방식으로 새 것을 만든다. 사용 예 /follow-pattern 기존 무기처럼 새 무기 '석궁' 추가
argument-hint: <참고할 기존 것> → <새로 만들 것>
---

요청: $ARGUMENTS

1. 참고할 기존 구현을 끝까지 따라가며 읽는다: 데이터 정의, 동작 코드, UI(도감·상점·카드), 스프라이트·프리팹, 저장 키, 패치노트 표기.
2. 새 것을 만들 때 손대야 하는 곳의 목록을 먼저 보여 준다.
3. 이름 규칙, 주석 밀도, 구조를 기존 코드와 똑같이 맞춰 구현한다. 새 추상화는 만들지 않는다.
4. `Assets/` 게임 스크립트에 `UnityEditor` 나 `System.Drawing` 이 들어가지 않았는지 확인한다.
5. 바꾼 파일을 모두 보고하고 AGENT.md 규칙대로 커밋한다.
