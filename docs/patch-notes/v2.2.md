# Gun Saver v2.2 패치노트

## 🆕 메뉴 · 설정 · 튜토리얼

- 메인 메뉴에 **튜토리얼**과 **설정** 버튼을 추가했습니다. 게임 중에는 `ESC` 메뉴에서 설정을 열 수 있습니다.
- **튜토리얼**: 기본 조작 · 필살기 · 성장 · 특수 능력 · 적과 보스 · 목표를 6쪽으로 알려줍니다.
- **언어**: 한국어(기본) · English · 日本語 · 中文
- **볼륨**: 0 ~ 100% (기본 50%)
- 설정은 저장되어 다음에 켤 때도 유지됩니다.

## 🎵 배경음악

- 직접 만든 배경음악 5곡을 추가했습니다: 메인 메뉴 · 지하 묘역 · 불타는 지옥 · 초원 · 보스전
- 보스가 나오면 **긴박한 보스전 음악**으로 바뀌고, 쓰러뜨리면 원래 곡으로 돌아갑니다.

## 🔫 무기 · 필살기

- **모든 총알**에 빛 무리 · 밝은 심 · 색 꼬리를 붙여 더 잘 보이게 했습니다.
- **즉발 필살기**: 산탄총 · 저격총 · 쌍권총 · 화염 방사기 · 유탄 발사기는 조준 화면 없이 우클릭 즉시 발동합니다.
- **필살기 이펙트와 소리 강화**
  - 쌍권총은 "탕탕" 총성, 산탄총은 두꺼운 굉음
  - 레일건은 충전음과 전기 파열음, 뇌운은 천둥
  - 죽음의 춤은 금속 베기, 화염 회오리는 굉음, 융단폭격은 큰 폭발음
- 저격총 조준선은 **발사 버튼을 누르고 있는 동안만** 화면 끝까지 닿는 점선으로 보입니다.

## 🐛 버그 수정

- 부메랑 낫 그림이 납작하게 찌그러져 거의 보이지 않던 문제
