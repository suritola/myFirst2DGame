# Soul Saver 2.0.0 패치노트 — 화면 정리 · 최적화

## 🟢 화면(UI) 정리

- 레벨업 카드 창 아래의 **선택 · 확정 안내와 [R] 카드 다시 뽑기 안내가 겹쳐 안 보이던 문제**를 고쳤습니다. 이제 두 줄로 나뉘어 보입니다.
- 레벨업 창 제목 띠가 왼쪽 위 체력 패널을 덮지 않도록 크기를 줄였습니다.
- 한글 문장이 **단어 중간에서 줄바꿈되던 문제**를 고쳤습니다. 이제 띄어쓰기 기준으로 줄이 바뀝니다. (카드 설명 등 게임 전체)
- 화면 위쪽 알림판 · 포털 카운트다운 · 「레벨 업!」 표시가 서로 겹치지 않게 차례로 쌓입니다.
- ESC 메뉴에서 **설정 버튼이 「[ESC] 계속하기」 안내를 가리던 문제**를 고쳤습니다. 오른쪽 「이번 판」 요약도 영혼 트리 버튼과 겹치지 않습니다.
- 게임 오버 화면에서 무한 모드 기록이 해골 그림과 겹치지 않게 버튼 아래로 옮겼습니다.
- 레벨업 대기 알림이 경험치 바 위 특수 강화 버튼과 겹치지 않습니다.
- 16:10 · 4:3 화면에서 영혼 트리 · 특수 능력 트리의 구석 버튼과 영혼 조각 칸이 잘리지 않습니다.

## ⚡ 최적화

- 필살기 조준 표시, 총알 · 적 탄 꼬리, 섬광 · 터짐, 불꽃 입자를 매번 새로 만들지 않고 다시 써서 전투 중 끊김을 줄였습니다.
