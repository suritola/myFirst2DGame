# Soul Saver 2.6 패치노트 — v2.2 ~ v2.6 합침

## 📦 v2.6

### 🎚️ 난이도: 쉬움 · 보통 · 어려움

- 메인 메뉴의 **게임 시작** 위에서 난이도를 고릅니다. 아직 열리지 않은 난이도는 회색으로 보입니다.
- 처음에는 **쉬움**만 할 수 있습니다. 지금까지의 게임이 쉬움입니다.
- **쉬움을 클리어하면 보통 · 어려움**이, **어려움을 클리어하면 무한 모드**가 열립니다.
- 난이도가 오르면 적의 체력 · 공격력 · 이동 속도, 스킬을 쓰는 빈도, 적이 나오는 속도와 수가 조금씩 올라가고 필살기 게이지는 조금 느리게 찹니다. 대신 경험치와 코인을 더 줍니다.

| | 쉬움 | 보통 | 어려움 |
|---|---|---|---|
| 적 체력 | 100% | 135% | 175% |
| 적 공격력 | 100% | 120% | 145% |
| 적 스킬 빈도 | 100% | 약 118% | 약 139% |
| 보스 체력 | 100% | 135% | 180% |
| 필살기 게이지 | 100% | 90% | 80% |
| 경험치 · 코인 | 100% | 115% | 130% |

### ♾️ 무한 모드 · 불타는 사막

- 어려움을 클리어하면 열리는 새 모드입니다. 새로 그린 **불타는 사막** 맵에서 시작합니다.
- 1 · 2 · 3장의 적이 모두 나오고, **리치 왕 → 지옥의 군주 → 킹 슬라임**이 번갈아 주기적으로 나타납니다.
- 처음에 특수 능력 3개를 고르고 시작하며, 보스를 쓰러뜨릴 때마다 특수 능력 포인트를 받습니다.
- 시간이 지날수록 적이 천천히 강해집니다. 화면 위에 생존 시간과 보스 처치 수가 보이고, 쓰러지면 **최고 기록**이 남습니다.
- 사막 전용 배경음악을 넣었습니다.

### 🎬 이야기

- 게임을 시작하면 검은 화면이 걷히며 주인공이 위에서 떨어지고, 짧은 이야기가 나옵니다.
- 3장까지 클리어하면 **엔딩 이야기**가 나옵니다.
- 모두 **Space · Enter · ESC** 나 **건너뛰기** 버튼으로 건너뛸 수 있습니다.

### ✨ 연출

- 필살기 조준 표시를 선 대신 **도트 그림**으로 바꿨습니다.
  - 부메랑 낫: 표적마다 도는 유령 낫과 흐르는 보라 화살촉 경로
  - 용암 유탄: 떨어질 자리마다 도는 룬 고리
  - 지옥불 산탄총 · 화염 회오리: 불꽃 화살촉 테두리
- 적을 쓰러뜨리면 스테이지 색의 **영혼 폭발**, 레벨업하면 **빛기둥**, 코인을 먹으면 **반짝임**이 나옵니다.
- 적 처치 · 레벨업 · 코인 획득 효과음을 새로 넣었습니다.

### ⚖️ 밸런스

- 필살기 게이지가 너무 빨리 찬다는 의견에 따라 **게이지 최대치를 25 → 40**으로 늘렸습니다.

### 🏆 스팀 도전 과제 6개 추가 (총 26개)

| 도전 과제 | 조건 |
|---|---|
| 새로운 도전 | 쉬움을 클리어해 보통 · 어려움 열기 |
| 한 걸음 더 | 보통 클리어 |
| 총잡이의 전설 | 어려움 클리어 |
| 사막의 방랑자 | 무한 모드 10분 생존 |
| 사막의 주인 | 무한 모드 20분 생존 |
| 왕들의 무덤 | 무한 모드 한 판에서 보스 5마리 처치 |

## 📦 v2.5

### ⚙️ 설정이 커졌습니다

설정 창이 **일반 · 화면 · 조작** 탭으로 나뉘었습니다.

- **일반**: 언어, 전체 볼륨에 더해 **음악 · 효과음 볼륨**을 따로 조절할 수 있습니다.
- **화면**
  - **전체 화면 / 창 모드**, **해상도**, **수직 동기화**를 고를 수 있습니다. 창 모드에서는 창 크기도 바꿀 수 있습니다.
  - **화면 흔들림**을 끌 수 있습니다.
  - **번쩍임 효과**를 끌 수 있습니다. 끄면 맞았을 때 붉은 번쩍임이 없어지고, 체력이 낮을 때의 붉은 테두리가 깜빡이지 않으며, 폭발 섬광이 옅어집니다.
- **조작**: 이동 · 재장전 · 무기 교체 · 스킬 1~3 · 상호작용 · 특수 강화 **키를 바꿀 수 있습니다.**
  - 이미 쓰는 키를 고르면 두 키가 서로 맞바뀝니다. **기본값으로** 버튼으로 되돌릴 수 있습니다.
  - 튜토리얼 · 도감 · 안내 문구의 키 이름도 바꾼 키를 따라갑니다.

### ⌨️ 스킬 3번 키가 `C`로 바뀌었습니다

- ⚠️ 세 번째 스킬의 기본 키가 `Space` → **`C`** 로 바뀌었습니다.
- `Space`는 이제 **상점 열기 · 레벨업 확정** 전용이라, 상점 제단 앞에서 스킬이 안 나가던 헷갈림이 없어졌습니다.
- 예전처럼 쓰고 싶다면 **설정 → 조작**에서 스킬 3을 `Space`로 바꾸면 됩니다.

### ⏸️ 일시정지

- **필살기를 조준하는 중에도 `ESC`로 멈출 수 있습니다.** 조준은 취소되고 필살기 게이지는 그대로 남습니다.
- 게임 창이 포커스를 잃으면 (Alt+Tab 등) **자동으로 일시정지** 메뉴가 열립니다.

### 🏆 스팀 도전 과제 10개 추가 (총 20개)

| 도전 과제 | 조건 |
|---|---|
| 다시 일어나라 | 처음으로 쓰러지기 |
| 단골 손님 | 떠돌이 상점을 처음 열기 |
| 손이 모자라 | 스킬 칸 3개를 모두 채우기 |
| 무기고 | 특수 무기 2개를 동시에 갖기 |
| 완전체 | 한 판에서 능력 3개 진화 |
| 필살기 중독 | 한 판에서 필살기 30번 사용 |
| 베테랑 | 한 판에서 레벨 15 달성 |
| 전설의 사냥꾼 | 누적 적 3,000마리 처치 |
| 완벽한 결투 | 피해를 받지 않고 보스 처치 |
| 구사일생 | 체력 10% 이하로 보스 처치 |

- 한국어 · English · 日本語 · 中文 모두 지원합니다.

### 🐛 버그 수정 · 개선

- 일시정지 메뉴의 **다시 시작**이 장면을 두 번 불러와 잠깐 멈칫하던 문제
- 스킬을 조준하는 도중 일시정지했다가 돌아오면 조준 표시가 남아 있던 문제
- 적이 많을 때 조금 더 부드럽게 돌아가도록 최적화했습니다.
- 설정을 바꾸고 창을 닫으면 바로 저장됩니다 (게임이 비정상 종료돼도 유지).
- 쓰지 않는 파일을 정리했습니다 (게임 내용 변화 없음).

### 🎵 배경음악

- 직접 만든 배경음악 5곡을 추가했습니다: 메인 메뉴 · 지하 묘역 · 불타는 지옥 · 초원 · 보스전
- 보스가 나오면 **긴박한 보스전 음악**으로 바뀌고, 쓰러뜨리면 원래 곡으로 돌아갑니다.

### 🔫 무기 · 필살기

- **모든 총알**에 빛 무리 · 밝은 심 · 색 꼬리를 붙여 더 잘 보이게 했습니다.
- **즉발 필살기**: 산탄총 · 저격총 · 쌍권총 · 화염 방사기 · 유탄 발사기는 조준 화면 없이 우클릭 즉시 발동합니다.
- **필살기 이펙트와 소리 강화**
  - 쌍권총은 "탕탕" 총성, 산탄총은 두꺼운 굉음
  - 레일건은 충전음과 전기 파열음, 뇌운은 천둥
  - 죽음의 춤은 금속 베기, 화염 회오리는 굉음, 융단폭격은 큰 폭발음
- 저격총 조준선은 **발사 버튼을 누르고 있는 동안만** 화면 끝까지 닿는 점선으로 보입니다.
