# Soul Saver 2.2.0 패치노트 — 난이도 곡선 · 거너 필살기 개편 · 보스 피해 숫자

## ⚖️ 난이도 곡선

- **초반은 더 쉽게, 후반은 더 어렵게** 바꿨습니다
  - 1장: 적 체력 · 주는 피해 0.5 → **0.42배**, 적이 더 드물고 느리게 나옵니다
  - 2장: 0.9 → **0.8배**, 적이 조금 덜 나옵니다
  - 3장: 원래보다 조금 세게 (**1.08배**), 4장: 확실히 세게 (**1.2배**) — 보스 체력도 같이, 적이 더 자주 · 많이 나오고 스킬도 자주 씁니다
- 무한 모드 · 체험판은 그대로입니다

## 🔫 거너 필살기

- **명중률 향상**: 한 적에게 여러 발을 쏠 때 방향을 첫 발 전에 한 번만 정해, 움직이는 적에게 뒤 총알이 빗나갔습니다
  - 이제 매 발 다시 조준하고, 발밑 대신 **몸 중심**을, 움직이는 적은 **갈 자리를 앞질러** 쏩니다
- **무기 진화 뒤 필살기**를 다른 캐릭터처럼 바꿨습니다
  - **쌍권총(총알 폭풍)**은 지금처럼 필살기가 총알 폭풍으로 바뀝니다
  - 샷건 · 저격총 · 화염 · 추적 · 번개 · 낫 · 유탄 진화는 **원래 조준 사격을 그대로** 쓰고, 끝나면 그 무기의 궁극기(지옥불 포격 · 관통 레일건 · 화염 회오리 …)가 **절반 세기로 덧붙습니다**
- **총알 폭풍 사거리**: 총알이 캐릭터 주위 **6칸**까지만 날아갑니다
  - 영혼 트리 **「폭풍 사거리」 I · II**로 2칸씩 늘어납니다 (최대 10칸) — 쌍권총일 때 쓸모없던 「노려보는 눈빛」 자리

## ✨ 더 잘 보이게

- **필살기 게이지가 가득 차면** 훨씬 화려하게 알려 줍니다
  - 차임이 「도 · 미 · 솔 · 도」로 올라가는 소리 + 반짝이는 소리
  - 게이지 뒤 금빛 후광이 크게 번쩍이고 게이지 틀이 튀어 오름, 가득 찬 동안 후광이 숨 쉬듯 커졌다 작아지고 1.2초마다 다시 번쩍, 게이지는 금색 ↔ 흰색으로 빠르게 반짝
- **보스에게 입힌 피해 숫자**가 거의 안 보이던 문제를 고쳤습니다
  - 큰 몸 꼭대기 위(화면 밖으로 잘리던 곳) 대신 몸 위쪽에서, 화면 안으로 맞춰 뜹니다
  - **1.8배 크기 · 주황 금색 · 두꺼운 테두리**로 더 오래 보이고, 연타는 모아서 큰 숫자 하나로

## 🐛 버그 수정

- 보스가 **결계**를 펼칠 때 결계 안 잡몹이 **맵 밖으로 밀려나던** 문제 — 이제 맵 안쪽 가장자리로 밀려납니다
- **코인 · 회복약**이 맵 밖에 떨어지지 않습니다 (보스 코인은 넓게 흩어지며 맵 밖에 떨어지곤 했음)
- 설정의 **「전체 화면」 · 「창 모드」** 버튼을 누르면 반대쪽 버튼에 불이 들어오던 문제 — 해상도 표시도 바로 바뀝니다

## 📜 패치노트

- 지난 패치노트를 **다섯 버전씩 하나로** 합쳐 보기 쉽게 정리했습니다
- 패치노트 화면에서 작은 제목이 「###」 기호째 보이던 문제를 고쳤습니다
