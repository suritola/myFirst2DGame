# Soul Saver 1.8.1 패치노트 — 스킬 키 표시 크게

## 🖥️ 화면

- **액티브 스킬 칸의 키 표시를 크게 바꿨습니다.** 너무 작아서 잘 안 보이던 문제입니다.
  - 글자 12 → **18 (굵게)**
  - 키 글자가 늘 **배지 위**에 나옵니다.
    - 설정 「키 아이콘」을 켜면 흰 키보드 키 모양입니다.
    - 끄면 어두운 배지에 금빛 글자라, 밝은 아이콘 위에서도 잘 보입니다.
  - 진화한 스킬의 " +" 표시까지 배지 안에 들어오도록 폭을 맞췄습니다.
- 무기 · 스킬 · 패시브 칸을 50 → 58로 조금 키웠습니다. 키 배지가 커져도 아이콘이 가려지지 않습니다.
