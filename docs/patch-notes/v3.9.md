## 📋 설명 형식 통일

- **모든 레벨업 카드**가 같은 모양입니다: 한 문장 설명 + 금색 **「수치  지금 → 다음」** + **Lv 지금 / 최대**
  - 예) 분열 화살 — 갈래 수 **2갈래 → 3갈래**  Lv 1 / 3
  - 예) 멀티 샷 — 발사 수 · 한 발당 피해도 지금 → 다음으로 함께 표시
- **모든 특수 능력**(무기 · 스킬 · 패시브)이 같은 모양입니다: 본문 + 파란 **「진화」** 줄
- 도감의 캐릭터 카드에는 레벨별 수치(예: 30% / 45% / 60%)가 모두 나옵니다.

## ⚔️ 몸 박치기

- 일반 적과 부딪혀도 **적이 죽지 않습니다.** 피해를 준 적은 살짝 튕겨 나갑니다.
- 맞은 뒤 무적 시간: 0.4초 → **0.6초**

## 👁️ 적 스킬이 더 잘 보이게

- 적이 스킬을 쓰는 동안 머리 위에 **스킬 이름**(예: 「도약!」, 「뼈 가시!」)이 까만 테두리 글씨로 뜹니다.
- 모든 경고 원 · 경고 띠(보스 포함) 밑에 **까만 테두리**를 깔아 어떤 바닥 색에서도 잘 보이고, 안쪽도 더 진해졌습니다.
- 기를 모으는 빛이 더 크고 밝아졌습니다.

## ✨ 특수 능력 선택 창

- 고른 능력은 **두꺼운 금빛 테두리가 맥박치고**, 오른쪽 위에 **고른 순서 번호(1 · 2 · 3)**가 붙습니다.
- 하나라도 고르면 나머지 능력은 더 어둡게 보입니다.
- 가진 능력에 마우스를 올리면 「한 번 더 고르면 진화합니다」가 표시됩니다.
