# Soul Saver 1.7.1 패치노트

> 이번 업데이트부터 버전 번호 형식이 바뀝니다. (v3.9 → 1.7.1)

## 🪧 안내 메시지를 작고 편하게

- 「떠돌이 상점이 나타났다!」, 「중간 보스 등장!」 같은 알림이 화면 가운데를 크게 가리던 것을, **화면 위쪽의 얇은 띠**로 바꿨습니다.
  - 반투명 배경, 부드럽게 나타났다가 서서히 사라집니다.
- 「레벨업!」 표시도 **작게 줄여** 위쪽에 띄웁니다.
- 캐릭터 주변의 레벨업 빛도 조금 작아졌습니다.

## 👹 중간 보스 표시 정리

- 금빛 후광과 도는 테두리를 없앴습니다.
- 머리 위에 **작은 이름표**(「중간 보스 · 이름」)만 체력바 바로 위에 붙습니다.
