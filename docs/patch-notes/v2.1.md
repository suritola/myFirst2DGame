# 민근이의 첫번째 게임 v2.1 패치노트

## 🎯 무기별 조준 화면

우클릭을 꾹 누르는 동안의 조준 화면이 들고 있는 무기의 필살기에 맞게 바뀝니다. 화면 색도 무기 색으로 물듭니다.

| 무기 | 조준 화면 |
|---|---|
| 지옥불 산탄총 | 마우스 쪽으로 펼쳐지는 불꽃 부채꼴, 안에 든 적에 조준경 |
| 영혼 저격총 | 충전될수록 굵어지는 레이저 조준선, 선 위의 적마다 조준경 |
| 저주받은 쌍권총 | 주위를 도는 금빛 룬 고리와 총구 섬광 |
| 화염 방사기 | 마우스 위치에 불꽃 룬과 회오리 미리보기 |
| 영혼 인도 지팡이 | 주위에 모여드는 영혼 구슬, 적마다 영혼 표식 |
| 번개 사슬총 | 커지는 먹구름, 적마다 번개 표식과 이어지는 번개 |
| 부메랑 낫 | 적마다 해골 표식과 베어 나갈 경로선 |
| 용암 유탄 발사기 | 운석이 떨어질 자리 격자 |

## 🛒 상점

- **스킬 강화 창**: 상점 왼쪽 위 탭에서 기본 권총과 보유 무기마다 필살기를 강화합니다.
  - **위력** +20% (5단계)
  - **특성** (3단계): 권총·낫 타겟 수 +2, 산탄총 포격 +1회, 저격총 광선 굵기, 쌍권총 지속, 화염 회오리 지속, 지팡이 구슬 +1, 사슬총 뇌운 지속, 유탄 폭격 줄 +2
- 기존의 "스킬 타겟 수" 항목은 스킬 강화 창의 기본 권총 특성으로 옮겼습니다.
- **상점 제단**
  - 이제 35마리마다 나타납니다 (전에는 10마리).
  - 가까이 가면 `[SPACE] 상점 열기` 말풍선이 뜨고, **Space를 눌러야** 열립니다. 의도치 않게 열리지 않아요.
