# Soul Saver 1.9.6 패치노트 — 순간이동 버그 수정 · 겹치는 능력 정리

## 🐞 버그 수정

- 모든 캐릭터가 적과 부딪힌 뒤 가끔 휙 밀려나 **순간이동한 것처럼 보이던 문제**를 고쳤습니다.

## ⚔️ 겹치던 능력 정리

레벨업 카드 · 영혼 트리와 효과가 같던 진화 능력과 카드를 서로 다른 효과로 바꿨습니다.

| 이전 | 바뀐 능력 |
|---|---|
| 화염 총구 — 총알이 불태움 (소각탄과 같음) | **화염 총구** — 쏠 때마다 총구 앞으로 짧은 불길이 뿜어짐 |
| 영혼 탄두 — 관통 · 탄속 · 치명타 (영혼 트리와 같음) | **영혼 탄두** — 사격을 잠깐 멈췄다 쏘면 첫 발이 모두 꿰뚫는 충전탄 (피해 250%) |
| 작열탄 — 맞은 자리 폭발 (폭발 탄두와 같음) | **점착탄** — 맞은 적에게 폭탄이 붙어 1.5초 뒤 폭발 |
| 추적 영혼탄 — 총알 유도 (유도 탄두와 같음) | **영혼 사냥** — 처치하면 적을 쫓는 영혼탄 두 발 |
| 뇌전 탄환 — 번개가 튐 (전기탄과 같음) | **낙뢰탄** — 여덟 번 맞힐 때마다 낙뢰 |
| 검사 창날 찌르기 (날아가는 검기와 같음) | **기사의 기세** — 움직이면서 베면 피해 +40% |
| 도적 와이어 표창 (도탄 표창과 같음) | **와이어 덫** — 맞은 적과 가까운 적을 줄로 묶어 둔화 |
| 궁수 연사 화살 (메아리 화살과 같음) | **속사 화살** — 시위를 25% 빨리 당기고, 반 이상 당기면 관통 +1 |
| 궁수 레벨업 카드 파열 화살 (2차 진화 폭발 화살과 같음) | **강풍 화살** — 가득 당긴 화살이 적을 밀쳐내고 잠깐 기절 |
