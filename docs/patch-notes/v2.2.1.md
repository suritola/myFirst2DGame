# Soul Saver 2.2.1 패치노트 — 거너 필살기에 영혼 탄환 · 총알 카드 적용

## 🔫 거너 필살기

- 필살기로 쏜 총알에 **영혼 탄환**이 붙지 않던 문제를 고쳤습니다
  - 필살기를 쓰는 순간 게이지가 비어서 "게이지가 가득 찬 동안" 조건을 만족하지 못했습니다
  - 이제 기본 권총 필살기(일제 사격)와 쌍권총 필살기(**총알 폭풍**)의 총알이 영혼탄이 됩니다
- 필살기 총알에도 **총알 카드와 고유 스킬**이 붙습니다 — 소각탄 · 전기탄 · 총열 과열 · 영혼 트리 치명타 등
  - 덤 총알 · 유도 · 폭발 탄두는 필살기 총알에는 붙지 않습니다 (너무 세지지 않게)
- 총알이 아닌 진화 무기 필살기(지옥불 포격 · 관통 레일건 · 화염 회오리 · 영혼 떼 · 뇌운 · 죽음의 춤 · 용암 융단폭격)는 영혼 탄환을 배웠으면 **피해가 그만큼 늘어납니다**
- 「영혼 탄환」 카드 설명에 필살기 적용을 적었습니다
