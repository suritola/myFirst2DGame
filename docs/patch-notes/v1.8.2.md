# Soul Saver 1.8.2 패치노트 — 액티브 스킬 제거 · 새 가지 '운명'

## ✂️ 액티브 스킬 제거

- 영혼 트리의 **스킬 가지**(키로 쓰는 액티브 스킬)를 없앴습니다. HUD의 스킬 칸도 더 이상 나오지 않습니다.
- 설정의 조작 목록에서 쓰지 않는 키(무기 교체 · 스킬 1~3)를 뺐고, "특수 강화" 키 이름은 **영혼 트리**로 바꿨습니다.

## 🔮 새 가지 '운명' (스킬 가지 자리)

다른 가지 · 레벨업 카드 · 거너 카드와 **겹치지 않는, 이전에 없던 효과**만 모았습니다. 모든 캐릭터가 같이 씁니다.

| 칸 | 효과 |
|---|---|
| **운명의 실** I~III | 레벨업 카드를 **[R]로 다시 뽑기**. 레벨이 오를 때마다 1회 채워지고 최대 1 → 2 → 3회 보관 |
| **시간의 틈** I~II | 체력이 30% 아래로 떨어지면 3 → 4초 동안 적이 65% 느려짐 (60 → 40초마다), 화면 가장자리가 푸르게 |
| **각성의 파동** I~II | 레벨이 오를 때 몸 주위에 충격파 (반경 6 → 9칸, 공격력 300 → 500%) |
| **연쇄 광풍** I~II | 4초 안에 12 → 8마리를 쓰러뜨리면 몸 주위에 폭풍 (공격력 250 → 350%) |
| **중력 우물** I~II | 25 → 15초마다 적이 가장 많이 몰린 곳에 3초 동안 적을 빨아들이는 우물, II는 마지막에 폭발 |
| **저주 전이** I~II | 적이 쓰러질 때 걸려 있던 화상 · 독 · 출혈이 가까운 적 2 → 4명에게 옮겨 감 |
| **영혼 메아리** I~II | 처치 시 6 → 12% 확률로 그 자리에 3초 동안 주변을 치는 유령 |

- 새 아이콘 7개를 그렸습니다.
- 도감의 **스킬** 탭은 **운명** 탭이 되었습니다. 도움말도 바꿨습니다.
