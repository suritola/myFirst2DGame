# Soul Saver 1.7.7 패치노트 — v1.7.3 ~ v1.7.7 합침

## 📦 v1.7.7 — 영혼 트리 대확장 (거너)

거너의 영혼 트리를 처음부터 다시 만들었습니다. 훨씬 넓어졌고, 배울수록 조금씩 드러나며, 무기가 진화해도 쌓은 강화가 사라지지 않습니다.

### 🌳 영혼 트리

- **여섯 가지로 늘었습니다**: 무기 · 필살기 · **스킬(새로)** · 생존 · 영혼 · **재물(새로)**.
  - 가운데 무기에서 사방으로 뻗고, 모두 약 100칸입니다.
- **다음 칸만 보입니다.**
  - 처음에는 가지마다 첫 칸만 보이고, 칸을 배우면 이어진 다음 칸이 드러납니다.
  - 화면 아래에 아직 숨어 있는 칸 수가 표시됩니다.
- **트리가 화면보다 큽니다.**
  - 빈 곳을 끌거나(좌 · 우클릭) WASD · 방향키로 움직이고, 휠로 확대 · 축소합니다.
  - [C]로 가운데로 돌아옵니다. 다시 열면 보던 자리 그대로입니다.
- 가지 색 범례가 위쪽에 있고, 배운 칸은 금색 테두리로 표시됩니다.

### ⚔️ 진화해도 그대로

- **무기 가지는 이제 모든 무기에 공통입니다.**
  - 피해 · 연사 · 탄창 · 장전 · 치명타 · 관통 · 탄속 · 처형이 권총에도 진화한 무기에도 그대로 적용됩니다.
  - 진화해도 배운 칸이 사라지지 않습니다.
- **무기 숙련 가지**: 들었던 무기마다 숙련 가지가 하나씩 덧붙습니다 (권총 → 1차 무기 → 2차 무기).
  - 숙련 보너스(모든 무기 피해 · 치명타 · 연사 · 관통)는 다음 무기에도 이어집니다.
  - 그 무기만의 특성(충전 속도 · 냉각 · 사거리 …)도 세 단계로 배울 수 있습니다.
- 필살기 특성 강화도 진화한 무기로 이어집니다.

### ✨ 새 능력

- **무기**
  - 급소 사격: 치명타. 피해 2배, 금색 총알로 보입니다.
  - 처참한 일격: 치명타 피해 2.6배.
  - 철갑탄: 관통 +1.
  - 고속탄: 탄속 +30%.
  - 처형: 체력 20% 아래 적에게 피해 +50%.
- **필살기**
  - 노려보는 눈빛: 조준 중 적이 더 느려집니다.
  - 잔불: 필살기를 쓴 뒤 게이지가 15 · 30% 남습니다.
- **스킬 (새 가지)**
  - 그림자 대시 · 지옥불 장판 · 시간 왜곡 등 8종 중 **3개**를 골라 배우고, 각각 진화시킵니다.
  - 모든 스킬 쿨타임 감소도 있습니다.
- **생존**
  - 영혼 보호막: 20초(강화 시 12초)마다 공격 한 번을 막습니다.
  - 가벼운 발: 이동 속도.
  - 피의 굶주림: 처치 시 회복.
- **재물 (새 가지)**
  - 코인 획득량 · 코인 자석 · 경험치 증가를 배웁니다.
  - **이자**: 30초마다 가진 코인의 5 · 10%를 받습니다 (최대 20개).

### 🏪 떠돌이 상점

- 거너는 이제 상점에서 **공격력 · 이동 속도**만 삽니다.
  - 무기가 바뀌어도 상관없는 기본 능력치만 남겼습니다.
  - 공격 속도 · 재장전 · 탄창은 무기마다 달라서, 진화한 무기에 제대로 적용되지 않던 문제가 있었습니다. 이제는 트리의 무기 가지에서 모든 무기에 공통으로 올립니다.
- 두 줄만 남아 상점 창도 작아졌습니다.

### 🔧 참고

- 다른 캐릭터(검사 · 도적 · 궁수 · 연금술사)의 영혼 트리 · 무기 진화는 다음 업데이트에서 이어집니다.
- 이번 버전도 GitHub 릴리즈로만 배포하고 스팀에는 올리지 않았습니다.

## 📦 v1.7.6 — 영혼 트리 사용성 개선

1.7.5에서 새로 넣은 거너 영혼 트리 · 무기 진화 화면을 실제 플레이 화면 기준으로 다듬었습니다.

### 🖥️ 화면 · 조작

- **영혼 트리 버튼을 오른쪽 위 구석에 작게** 옮겼습니다 (코인 · 포인트 표시 아래).
  - 화면 아래 가운데에 크게 떠 있던 버튼이 시야를 가리던 문제를 고쳤습니다.
  - 버튼에는 "영혼 트리 [T] 조각 수"만 짧게 보입니다.
  - 살 수 있는 칸이 있을 때만 은은하게 반짝입니다.
- **영혼 트리에서 칸 설명창이 트리 뒤에 가려지던 문제를 고쳤습니다.** 이제 설명창이 항상 맨 위에 보입니다.
- **영혼 트리 배치를 새로 바꿨습니다.**
  - 네 가지(무기 · 필살기 · 생존 · 영혼)가 네 귀퉁이 쪽으로 뻗습니다.
  - 가지 안에서는 깊이가 가로 칸, 갈래가 세로 줄입니다. 칸과 글자가 서로 겹치지 않습니다.
- 영혼 트리 · 무기 진화 화면이 HUD(체력 · 코인 · 능력치 패널 · 경험치 바)보다 확실히 위에 그려집니다. 뒤 화면이 비치거나 안내문이 가려지지 않습니다.
- 거너의 무기 칸 제목에서 **[Q]** 표시를 뺐습니다 (거너는 무기 교체가 없음).

### ✨ 덜 산만하게

- 적을 쓰러뜨릴 때마다 터지던 보라색 반짝임을 없앴습니다. 영혼 조각은 조용히 쌓입니다.
- "영혼 조각 +N" 글자와 반짝임은 **중간 보스 · 보스**를 잡을 때만 보입니다.
- 보스를 쓰러뜨렸을 때 "신전 문이 열렸다" 알림이 진화 화면에 바로 가려지던 문제를 고쳤습니다. 이제 진화를 고른 뒤에 알림이 뜹니다.
- 처음으로 영혼 조각이 칸 하나를 살 만큼 모이면 "[T]로 영혼 트리를 여세요" 안내가 한 번 뜹니다.

### 🐞 버그 수정

- 영혼 트리 · 무기 진화 화면이 가끔 저절로 사라지던 문제를 고쳤습니다.
  - 원인: 화면을 붙일 캔버스를 고를 때 적 머리 위 이름표 캔버스가 골라질 수 있었고, 그 적이 죽으면 창도 함께 사라졌습니다.
  - 알림 · 시계 · 판 요약 창 등 다른 화면 UI도 모두 항상 HUD 화면에 붙도록 바꿨습니다.

### ⚡ 성능

- 거너의 영혼 트리 버튼이 적을 잡을 때마다 트리 전체를 새로 만들어 확인하던 것을 줄였습니다 (최대 0.5초에 한 번, 아이콘 검색은 한 번만).
- 버튼 글자를 매 프레임 새로 만들던 것을 조각 수 · 키 · 언어가 바뀔 때만 쓰도록 바꿨습니다.
- 같은 PC 상태에서 1.7.4와 비교해 적 60마리 전투의 평균 프레임 시간이 같은 수준입니다 (거너 5.42 → 5.46ms, 도적 7.56 → 7.79ms, 측정 오차 범위).

### 🔧 참고

- 이번 버전도 GitHub 릴리즈로만 배포하고 스팀에는 올리지 않았습니다.

## 📦 v1.7.5 — 거너 성장 방식 개편 (무기 진화 · 영혼 트리)

거너부터 성장 방식을 새로 바꿨습니다. 무기를 바꿔 드는 대신 **무기 하나가 진화**하고, 스킬은 **영혼 트리**에서만 강화합니다.
다른 캐릭터는 아직 예전 특수 능력 방식을 씁니다 (거너로 먼저 시험해 보고 넓힐 예정).

### ⚔️ 무기 진화 (거너)

- 스테이지 보스를 쓰러뜨리면 화면이 어두워지고 빛이 모인 뒤, 지금 무기가 부서지며 **진화 카드 3장**이 펼쳐집니다.
- 카드를 누르거나 [1] [2] [3]으로 고르고, 버튼이나 [상호작용]으로 확정합니다. **되돌릴 수 없습니다.**
- 진화는 **두 번**입니다.
  - 1차 (1장 보스): 권총 → 화염 방사기 / 영혼 저격총 / 저주받은 쌍권총
  - 2차 (2장 보스): 계열마다 세 갈래
    - 화염: **지옥불 방사기** / 용암 유탄 발사기 / 지옥불 산탄총
    - 저격: **영혼 레일건** / 영혼 인도 지팡이 / 번개 사슬총
    - 쌍권총: **심판의 쌍권총** / 부메랑 낫 / 번개 사슬총
  - 같은 계열을 한 번 더 고르면 이름이 바뀌고 진화 효과가 붙은 극대화판이 됩니다.
- 무기 강화와 필살기 강화 단계는 진화한 무기로 그대로 이어집니다.
- 무기 교체([Q])와 HUD의 권총 칸은 거너에게 더는 없습니다.
- 무한 모드에서는 시작할 때 1차 진화를 고르고, 보스를 잡을 때마다 남은 진화가 이어집니다.

### 🌳 영혼 트리 (거너, [T])

- 가운데에 지금 무기가 있고, 네 갈래가 대각선으로 뻗습니다: **무기 · 필살기 · 생존 · 영혼**.
- 칸을 누르면 영혼 조각으로 바로 배웁니다. 앞 칸을 배워야 이어진 칸이 열립니다.
- 무기 가지는 **무기마다 다릅니다.**
  - 진화 전에는 권총 강화입니다.
  - 진화 뒤에는 그 무기의 피해 · 연사 · 탄창 · 고유 특성입니다 (예: 저격총 충전 속도, 화염 냉각).
- 필살기 가지에는 위력 · 빠른 충전과 함께 **무기마다 다른 필살기 특성**이 있습니다 (타겟 수, 회오리 지속, 광선 굵기 등).
- 생존 가지: 최대 체력 · 회복력 · 받는 피해 감소 · 맞은 뒤 무적 시간.
- 영혼 가지: 영혼 조각 획득량과 예전 거너 패시브(수호 영혼 · 복수의 가시 · 탄창 저주 · 불사의 맹세)를 배우고 진화합니다.
- 화면 아래 버튼에 영혼 조각 수가 늘 보이고, 살 수 있는 칸이 있을 때만 반짝입니다.

### 💠 영혼 조각 (새 재화)

- 적을 쓰러뜨리면 모입니다. 골드와는 별개이고 판마다 새로 시작합니다.
- 강한 적일수록 많이 줍니다: 일반 < 강한 적 < 중간 보스 < 스테이지 보스.

### 🏪 떠돌이 상점

- **무기 강화 · 스킬 강화 창을 없앴습니다.** 무기는 진화로, 스킬은 트리로만 강화합니다.
- 상점에는 능력치 강화만 남습니다.

### 🃏 레벨업 카드

- 스킬 관련 카드 **재활용 에너지**를 모든 캐릭터에서 뺐습니다.
- 거너의 무기 관련 카드(관통 · 멀티 샷 · 밀어내기 · 노려보는 눈빛)를 **총알이 하는 일을 바꾸는 거너 전용 카드 6장**으로 바꿨습니다. 권총에도, 진화한 모든 무기에도 붙습니다.

| 카드 | 효과 | 단계 |
|---|---|---|
| 도탄 사격 | 맞힌 적에게서 가까운 다른 적에게 작은 탄이 튕겨 나감 | 튕긴 탄 피해 40 / 55 / 70% |
| 폭발 탄두 | 몇 발마다 한 발이 맞은 자리에서 폭발 | 5 / 4 / 3번째마다 |
| 소각탄 | 맞은 적이 2초 동안 불탐 | 초당 공격력 15 / 25 / 35% |
| 유도 탄두 | 총알이 가까운 적 쪽으로 휨 | 약하게 / 보통 / 강하게 |
| 전기탄 | 맞힐 때 확률로 번개가 주변 적 둘에게 튐 | 15 / 25 / 35% |
| 장전 충격파 | 장전을 시작하면 몸 주변에 충격파 | 공격력 100 / 160 / 220% |

- 다른 캐릭터의 전용 카드는 이미 기본 공격을 바꾸는 카드라 그대로 둡니다.

### 📖 도감 · 도움말

- 도감에 거너 전용 카드 6장과 무기 진화 · 영혼 트리 설명을 넣었습니다.
- 더는 나오지 않는 카드와 상점 창 설명을 뺐습니다.
- 도움말에 거너의 무기 진화 · 영혼 트리 항목을 넣었습니다.
- 새 글은 모두 영어 · 일본어 · 중국어로 번역했습니다.

### 🔧 참고

- 이번 버전은 GitHub 릴리즈로만 배포하고 스팀에는 올리지 않았습니다.

## 📦 v1.7.4 — 성능 최적화

게임 규칙 · 밸런스 · 보이는 모습은 **그대로** 두고, 같은 일을 더 적은 비용으로 하도록 코드만 바꿨습니다.

### 📊 측정 결과

같은 조건(적 45~60마리 · 공격 0.1초마다 · 900프레임)으로 최적화 전(1.7.3)과 후(1.7.4)를 **각각 두 번씩** 재서 평균을 냈습니다.

**적이 많은 전투 (적 + 공격)**

| 캐릭터 | 항목 | 1.7.3 | 1.7.4 | 변화 |
|---|---|---|---|---|
| 도적 | 평균 프레임 시간 | 6.37ms | **4.71ms** | **-26%** |
| 도적 | 끊김 (느린 1% 프레임) | 30.24ms | **18.64ms** | **-38%** |
| 도적 | 프레임당 가비지 | 20.42KB | **2.49KB** | **-88%** |
| 거너 | 평균 프레임 시간 | 7.14ms | **5.63ms** | **-21%** |
| 거너 | 끊김 (느린 1% 프레임) | 25.75ms | **18.27ms** | **-29%** |
| 거너 | 프레임당 가비지 | 18.09KB | **2.73KB** | **-85%** |

**적 60마리만 움직일 때**

| 캐릭터 | 평균 프레임 | 프레임당 가비지 |
|---|---|---|
| 도적 | 5.41 → **4.16ms** (-23%) | 14.97 → **1.22KB** (-92%) |
| 거너 | 6.50 → **5.17ms** (-20%) | 14.25 → **2.23KB** (-84%) |

**공격만 할 때 (적 없음)**

| 캐릭터 | 평균 프레임 | 프레임당 가비지 |
|---|---|---|
| 도적 | 1.89 → **1.46ms** (-23%) | 13.83 → **0.34KB** (-98%) |
| 거너 | 1.74 → **1.52ms** (-13%) | 8.42 → **0.29KB** (-97%) |

> 가비지(메모리 쓰레기)가 쌓이면 주기적으로 청소가 돌면서 화면이 순간 멈칫합니다. 이번 최적화로 가비지가 약 85~98% 줄어 **순간 끊김이 크게 줄었습니다.**

### 🔧 바꾼 것

1. **맞을 때마다 남기던 로그 제거** — 적 · 보스가 맞을 때마다, 점수가 오를 때마다 로그 파일에 글을 썼습니다. (게임에는 안 보이는 개발용 기록)
2. **매 프레임 씬 전체 검색 없애기**
   - 코인 자석: 매 프레임 모든 코인을 태그로 찾던 것 → 떨어진 코인이 스스로 목록에 등록
   - 총알 · 적: 하나 생길 때마다 플레이어를 씬 전체에서 찾던 것 → 한 번 찾아 둔 것을 씀
   - 보스 이름 글자를 못 찾으면 매 프레임 찾던 것 → 1초에 한 번
3. **물리 검색 결과 다시 쓰기** — 가장 가까운 적 찾기(패시브 · 유도탄 · 분신 등), 수호 영혼, 화염 회오리, 마름쇠, 자석 끌어당기기가 매번 새 배열을 만들던 것을 목록 하나로 다시 씀 (결과는 똑같음)
4. **글자는 바뀔 때만 새로** — 체력 · 레벨 · 탄약 · 플레이 시간 · 무한 모드 표시가 매 프레임 글자를 새로 만들던 것
5. **능력 HUD** — 쿨타임 원은 매 프레임 그대로, 글자(남은 초 · 탄창 · 중첩)는 0.1초마다 바뀔 때만
6. **레벨업 카드 글** — 창이 닫혀 있을 때도 매 프레임 15장의 설명을 새로 만들던 것 → 창이 열려 있을 때만
7. **피해 숫자 다시 쓰기** — 맞을 때마다 글자 오브젝트를 만들고 지우던 것 → 다 떠오른 숫자를 꺼 두었다가 다시 씀
8. **이펙트 다시 쓰기** — 폭발 · 불꽃 · 먼지 같은 만들고 잊는 이펙트 167곳이 매번 오브젝트를 만들고 지우던 것 → 끝난 이펙트를 꺼 두었다가 다시 씀 (누가 붙잡고 쓰는 이펙트는 그대로)
9. **적 이동 계산** — 벽 확인 순서를 바꿔 대부분 검색 한 번으로 끝냄, 주변 적 밀어내기에서 적마다 부품을 찾던 것 → 대응표
10. **작은 것들** — 적 체력바는 체력이 바뀔 때만 다시 그림, 음악은 장면이 바뀔 때만 장면 이름을 확인, 이펙트 정렬 층 이름을 한 번만 찾음, 이번 판 기록이 0.5초마다 씬을 뒤지던 것

- 게임 규칙 · 수치 · 밸런스 변화 없음

## 📦 v1.7.3

### ⬆️ 레벨업: 포인트를 모아 원할 때 고르기

- 레벨이 올라도 **능력 선택 창이 바로 뜨지 않습니다.** 대신 레벨업 포인트가 쌓이고, 화면 아래에 「레벨업!  [Space] 능력 고르기  x2」처럼 표시됩니다.
- **Space**를 누르면 그때 능력 선택 창이 열립니다. 싸우는 중에 흐름이 끊기지 않습니다.
- 상점 가판대 옆에서는 Space가 상점을 먼저 엽니다.
- 무한 모드의 시작 레벨 10도 포인트 9개로 쌓여, 원할 때 하나씩 고릅니다.
