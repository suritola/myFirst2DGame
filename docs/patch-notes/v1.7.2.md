# Soul Saver 1.7.2 패치노트 — v3.7 ~ v1.7.2 합침

## 📦 v1.7.2

### ⚔️ 검사: 근접 특성

적에게 붙어 싸워야 하는 검사가 계속 맞기만 하던 문제를 고쳤습니다. 검사는 처음부터 다음 특성을 가집니다.

- **휘두르는 동안 받는 피해 절반** (휘두른 뒤 0.3초)
- **벤 적을 크게 밀쳐냄** (몸에 닿기 전에 밀려남)
- **벤 적 하나당 체력 0.3 회복** (한 번에 최대 3마리). 「흡혈 베기」 카드는 여기에 레벨마다 +1

### ⚖️ 밸런스

| 항목 | 전 | 후 |
|---|---|---|
| 몸 박치기 피해 (모든 일반 적) | 100% | **60%** |
| 받는 피해 감소 합계 최대 | 제한 없음 (무적 가능) | **70%** |
| 도적 장전 시간 | 1.8초 | **1.0초** |
| 궁수 체력 | 거너의 50% | **65%** |
| 궁수 가득 당긴 화살 | 250% | **280%** |
| 연금술사 공격력 | 거너의 90% | **80%** |
| 약점 간파 (궁수 패시브) | +50% / 진화 +100% | **+35% / 진화 +70%** |

### 🧭 편의 기능

- **도움말**: 처음 한 번씩, 필요한 순간에 짧은 안내가 화면 아래에 뜹니다. (이동 · 필살기 · 무기 교체 · 스킬 · 특수 강화 · 상점)
- **ESC 요약**: 일시정지하면 오른쪽에 이번 판 요약(시간 · 레벨 · 처치 · 능력치 · 특수 능력 · 레벨업 카드)이 나옵니다.
- **저체력 심장 박동**: 체력이 30% 아래면 붉은 테두리와 함께 심장 소리가 납니다.
- **결과 화면**: 게임 오버 화면 왼쪽에 이번 판 결과가 나옵니다.
- **빠른 재시작**: 게임 오버 화면에서 **R**을 누르면 같은 캐릭터 · 난이도로 바로 다시 시작합니다.

### ⚙️ 설정 「게임」 탭 (새로 추가)

- **도움말 안내** 켜짐 / 꺼짐
- **피해 숫자** 보통 / 크게 / 끄기
- **색각 이상 모드**: 경고 표시를 빨강 · 초록 대신 구분하기 쉬운 주황 · 파랑 · 자홍으로
- **키 아이콘**: HUD 스킬 칸의 키를 키보드 키 모양으로 (끄면 글자만)

### 🐛 수정

- 1.7.1에서 알림판 설정 코드가 일부 환경에서 게임 시작을 멈출 수 있던 문제

### 📋 설명 형식 통일

- **모든 레벨업 카드**가 같은 모양입니다: 한 문장 설명 + 금색 **「수치  지금 → 다음」** + **Lv 지금 / 최대**
  - 예) 분열 화살 — 갈래 수 **2갈래 → 3갈래**  Lv 1 / 3
  - 예) 멀티 샷 — 발사 수 · 한 발당 피해도 지금 → 다음으로 함께 표시
- **모든 특수 능력**(무기 · 스킬 · 패시브)이 같은 모양입니다: 본문 + 파란 **「진화」** 줄
- 도감의 캐릭터 카드에는 레벨별 수치(예: 30% / 45% / 60%)가 모두 나옵니다.

### ⚔️ 몸 박치기

- 일반 적과 부딪혀도 **적이 죽지 않습니다.** 피해를 준 적은 살짝 튕겨 나갑니다.
- 맞은 뒤 무적 시간: 0.4초 → **0.6초**

### 👁️ 적 스킬이 더 잘 보이게

- 적이 스킬을 쓰는 동안 머리 위에 **스킬 이름**(예: 「도약!」, 「뼈 가시!」)이 까만 테두리 글씨로 뜹니다.
- 모든 경고 원 · 경고 띠(보스 포함) 밑에 **까만 테두리**를 깔아 어떤 바닥 색에서도 잘 보이고, 안쪽도 더 진해졌습니다.
- 기를 모으는 빛이 더 크고 밝아졌습니다.

### ✨ 특수 능력 선택 창

- 고른 능력은 **두꺼운 금빛 테두리가 맥박치고**, 오른쪽 위에 **고른 순서 번호(1 · 2 · 3)**가 붙습니다.
- 하나라도 고르면 나머지 능력은 더 어둡게 보입니다.
- 가진 능력에 마우스를 올리면 「한 번 더 고르면 진화합니다」가 표시됩니다.

## 📦 v3.8

### 🖥️ 한눈에 보는 HUD

- 왼쪽 아래 무기 · 스킬 · 패시브 창을 **아이콘 칸**으로 바꿨습니다.
  - 스킬: 쿨타임이 어두운 원으로 줄어들고, 남은 초와 키(E · F · C)가 표시됩니다.
  - 무기: 탄창(6/12) · 장전 · 열기, 들고 있는 무기는 금색 테두리
  - 패시브: 중첩(x3), 지금 오른 수치(+32%), 준비 · 남은 초, 켜짐(ON) · 꺼짐(OFF)
  - 마우스를 올리면 **자세한 설명과 지금 상태**가 나옵니다.
- 창 이름표를 누르면 **접었다 폈다** 할 수 있습니다. (접힌 상태는 저장)
- 모든 난이도에서 화면 위에 **플레이 시간(00:00)**이 보입니다.

### 🧙 캐릭터마다 패시브 4개

캐릭터마다 새 패시브를 2개씩 더했습니다.

| 캐릭터 | 새 패시브 |
|---|---|
| 검사 | **기사의 맹세** 체력이 가득하면 공격력 +20% · **강철 갑옷** 받는 피해 -15% (대신 5% 느림) |
| 도적 | **그림자 은신** 3초 동안 안 맞으면 다음 평타 2배 · **도망자의 발걸음** 맞으면 1.5초 동안 +40% 빨라짐 |
| 궁수 | **약점 간파** 체력이 가득한 적에게 +50% · **사냥 본능** 20마리마다 화살 3발이 저절로 가득 당겨짐 |
| 연금술사 | **비상 물약** 체력 25% 아래로 떨어지면 30% 회복 (45초) · **금속 변환** 처치 시 10% 확률로 코인 3개 |

### 🃏 레벨업 카드

- 캐릭터 전용 카드를 2장씩 더했습니다.
  - 검사: **굳건한 자세**(회전 베기를 모으는 동안 받는 피해 감소) · **연속 베기**(네 번째 베기마다 강한 일격)
  - 도적: **급소 노리기**(출혈 중인 적에게 피해 증가) · **표창 회수**(탄창이 비면 확률로 절반 회수)
  - 궁수: **정조준**(가만히 서서 당기면 더 빨리) · **사냥감 표식**(가득 당긴 화살에 맞은 적이 피해를 더 받음)
  - 연금술사: **원소 융합**(불타는 적 + 빙결 = 증기 폭발) · **끈적한 산성**(산성 웅덩이가 적을 느리게)
- 끝없이 고를 수 있던 **강철같은 심장 · 코인충 · 더 많은 경험치**에 최대 레벨(4)을 두었습니다. 최대 체력이 1000을 넘던 문제를 막습니다.
- 고를 능력을 모두 배운 뒤에는 **비상 보급**(체력 30% + 코인 10)이 나옵니다. (전에는 카드가 모자라면 멈출 수 있었습니다)

### ♾️ 무한 모드

- **레벨 10으로 시작**합니다. 레벨업 카드 9장을 시작할 때 차례로 고릅니다.
- 처음에는 **1장의 약한 적만** 나오고, 처치할수록 강한 적이 차례로 풀립니다. 약한 적도 계속 섞여 나옵니다.
- 시작 난이도는 보통 수준으로 낮추고, 대신 시간이 지날수록 더 가파르게 강해집니다. (1분마다 +8%, 최대 +130%)

### 👹 중간 보스

- 머리 위에 **「중간 보스 · 이름」 이름표**가 붙고, **금색으로 맥박치는 후광과 도는 테두리**가 생겨 한눈에 보입니다.

### 🐛 수정

- 경험치 막대가 잠깐 꺼져 있을 때 적을 처치하면 오류가 나던 문제

## 📦 v3.7

### ⏩ 게임 템포 약 30% 빠르게

보스가 나오기까지 필요한 처치 수를 줄이고 적이 더 빨리 나오게 했습니다. 난이도마다 목표 클리어 시간이 다릅니다.

| 난이도 | 필요한 처치 수 | 적 생성 간격 | 목표 클리어 시간 |
|---|---|---|---|
| 쉬움 | 70% | 80% | 20분 내외 |
| 보통 | 80% | 80% | 25분 내외 |
| 어려움 | 90% | 85% | 30분 내외 |

- 처치 수가 줄어든 만큼 **경험치와 코인을 더 줘서**, 스테이지마다 성장하는 정도는 전과 비슷합니다.
- 무한 모드는 그대로입니다.

### 👑 보스: 체력은 낮게, 공격은 세게

보스 자체는 쉬운데 체력만 많아 지루하던 문제를 고쳤습니다. 이제 1 ~ 3분 안에 잡을 수 있습니다.

| 보스 | 체력 |
|---|---|
| 1장 리치 왕 | 800 → **480** |
| 2장 지옥의 군주 | 4500 → **2400** |
| 3장 킹 슬라임 | 본체 2600 → **1400**, 분열체 1100 → **600**, 작은 분열체 500 → **280** |

- 난이도별 보스 체력 배율: 보통 1.35 → **1.2**, 어려움 1.8 → **1.4**
- 대신 보스의 스킬과 공격이 **25% 더 아프고**, 스킬을 더 자주 씁니다. (스킬 간격 4.5초 → 3.6초, 분노 시 3.2초 → 2.6초, 특수 스킬 16초 → 12초)

### 🛡️ 피격 무적 시간

- 맞은 뒤 무적 시간: 0.8초 → **0.4초**

### 🛒 상점

- 「레벨업!」 표시가 뜬 상태로 상점을 열면 표시가 화면을 가리던 문제를 고쳤습니다. 상점이 열려 있는 동안은 숨겨집니다.
- 상점 가판대에서 **Space로 여는 거리를 2배**로 늘렸습니다. (3칸 → 6칸)
