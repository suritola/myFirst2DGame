# Soul Saver 1.7.2 패치노트

## ⚔️ 검사: 근접 특성

적에게 붙어 싸워야 하는 검사가 계속 맞기만 하던 문제를 고쳤습니다. 검사는 처음부터 다음 특성을 가집니다.

- **휘두르는 동안 받는 피해 절반** (휘두른 뒤 0.3초)
- **벤 적을 크게 밀쳐냄** (몸에 닿기 전에 밀려남)
- **벤 적 하나당 체력 0.3 회복** (한 번에 최대 3마리). 「흡혈 베기」 카드는 여기에 레벨마다 +1

## ⚖️ 밸런스

| 항목 | 전 | 후 |
|---|---|---|
| 몸 박치기 피해 (모든 일반 적) | 100% | **60%** |
| 받는 피해 감소 합계 최대 | 제한 없음 (무적 가능) | **70%** |
| 도적 장전 시간 | 1.8초 | **1.0초** |
| 궁수 체력 | 거너의 50% | **65%** |
| 궁수 가득 당긴 화살 | 250% | **280%** |
| 연금술사 공격력 | 거너의 90% | **80%** |
| 약점 간파 (궁수 패시브) | +50% / 진화 +100% | **+35% / 진화 +70%** |

## 🧭 편의 기능

- **도움말**: 처음 한 번씩, 필요한 순간에 짧은 안내가 화면 아래에 뜹니다. (이동 · 필살기 · 무기 교체 · 스킬 · 특수 강화 · 상점)
- **ESC 요약**: 일시정지하면 오른쪽에 이번 판 요약(시간 · 레벨 · 처치 · 능력치 · 특수 능력 · 레벨업 카드)이 나옵니다.
- **저체력 심장 박동**: 체력이 30% 아래면 붉은 테두리와 함께 심장 소리가 납니다.
- **결과 화면**: 게임 오버 화면 왼쪽에 이번 판 결과가 나옵니다.
- **빠른 재시작**: 게임 오버 화면에서 **R**을 누르면 같은 캐릭터 · 난이도로 바로 다시 시작합니다.

## ⚙️ 설정 「게임」 탭 (새로 추가)

- **도움말 안내** 켜짐 / 꺼짐
- **피해 숫자** 보통 / 크게 / 끄기
- **색각 이상 모드**: 경고 표시를 빨강 · 초록 대신 구분하기 쉬운 주황 · 파랑 · 자홍으로
- **키 아이콘**: HUD 스킬 칸의 키를 키보드 키 모양으로 (끄면 글자만)
