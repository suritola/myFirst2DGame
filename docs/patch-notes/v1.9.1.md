# Soul Saver 1.9.1 패치노트 — 스킨 효과가 확실하게

스킨 상점에서 산 이펙트 스킨이 잘 보이지 않던 문제를 고쳤습니다.

## ✨ 이펙트 스킨

- **모든 캐릭터**에서 적 · 보스를 맞히면 스킨 색 명중 불꽃이 튑니다. 예전에는 거너 총알에만 적용됐습니다.
- 적을 쓰러뜨릴 때 나오는 **기본 처치 효과(영혼 폭발)가 스킨 색으로** 바뀝니다. 별의 축복은 무지갯빛입니다.
- 처치 소리가 두 배 이상 커졌고, 코인 반짝임도 커졌습니다.

| 스킨 | 바뀐 점 |
|---|---|
| 푸른 불꽃 | 처치할 때 푸른 불꽃이 흩날림 (새로 추가) |
| 벚꽃 | 꽃잎이 더 크고 많이 흩날림 |
| 뇌전 | 처치하면 **하늘에서 번개가 내리꽂히고** 노란 충격파가 퍼짐, 명중 세 번에 한 번 작은 전기가 튐 |
| 별의 축복 | 별가루가 더 많이 터지고 흰 충격파가 퍼짐 |

## 🧥 캐릭터 스킨

- 영웅 등급 스킨의 이동 잔상이 더 진해졌습니다.
- 전설 등급 스킨의 오라 · 바닥 빛이 더 진해졌습니다.
