# Gun Saver v2.7 패치노트

## 🔫 영혼 저격총

- **조준선이 화면 끝까지 닿는 점선**으로 보입니다. 무기를 들고 있으면 항상 보이고, 충전할수록 밝고 굵어지며 완충되면 금색으로 바뀝니다.
- **꾹 누르고 있으면 발사됩니다.** 누르고 있으면 완충되는 순간 쏘고, 계속 누르고 있으면 다시 충전해 이어서 쏩니다. 일찍 떼면 지금처럼 그만큼 충전한 채로 쏩니다.
- 필살기 **관통 레일건**의 조준선도 화면 끝까지 닿는 점선으로 바꿨습니다.

## 🌙 부메랑 낫 (너프)

- 같은 적은 **날아갈 때 한 번, 돌아올 때 한 번**만 맞습니다. (적이 밀려났다 다시 닿을 때마다 여러 번 맞던 문제)
- 피해량을 약 20% 낮췄습니다. (공격력의 150% → 120%, 진화 220% → 175%)
- 이제 **벽을 통과합니다.** 벽에 닿으면 사라지면서 바로 다시 던질 수 있어 벽 앞에서 엄청 빠르게 연사되던 문제를 고쳤습니다.

## 🐛 그 밖에

- 점선으로 보여야 할 조준 표시(낫 · 유탄 조준선, 스킬 미리보기 등)가 실선으로 그려지던 문제를 고쳤습니다. 이제 흘러가는 화살촉 점선으로 보입니다.
