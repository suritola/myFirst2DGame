# Soul Saver 2.1.9 패치노트 — 판 중간 저장 · 플레이 튜토리얼

## 💾 판 중간 저장 · 이어하기

- 이제 판을 **중간에 저장하고 이어서** 할 수 있습니다
- **저장되는 때**: ESC → 메인 메뉴로 나갈 때 · 게임 창을 닫을 때 · 다음 장에 들어갈 때 (자동)
- 메인 메뉴의 **「이어하기」** 버튼에 저장된 판의 캐릭터 · 장 · 레벨이 보입니다
- 고른 레벨업 카드 · 스킬 진화 · 무기 진화 · 영혼 트리 · 상점 강화와 체력 · 경험치 · 남은 레벨업 · 코인 · 영혼 조각 · 처치 수 · 필살기 게이지가 그대로 이어집니다
  - 보스와 싸우던 중이었다면 그 보스부터 다시 싸웁니다
  - 보스를 쓰러뜨리고 무기 진화를 고르기 전이었다면 진화부터 고릅니다
- 죽거나 4장을 클리어하면 저장된 판은 지워집니다
- 저장된 판이 있을 때 **「게임 시작」**을 누르면 새 게임을 시작할지 한 번 더 묻습니다
- 무한 모드 · 일일 도전 · 체험판은 저장하지 않습니다

## 🎓 튜토리얼이 직접 해 보는 방식으로

- 글을 읽는 대신 **실제 게임 화면에서 하나씩 직접 해 보며** 익힙니다 (거너로 진행)
  1. 이동
  2. 조준 · 공격
  3. 재장전
  4. 필살기 (게이지를 채워 줍니다)
  5. 레벨업 카드 고르기 (레벨업 포인트를 줍니다)
  6. 영혼 트리 (영혼 조각을 줍니다)
  7. 무기 진화
  8. 진화한 무기로 마무리
- 화면 위 안내 띠에 지금 할 일과 진행 막대가 보이고, 해내면 **「✔ 완료!」**
- 약한 적만 나오고 **죽지 않습니다** — 싸움보다 조작을 익히는 데 집중
- 오른쪽 위 **[튜토리얼 그만두기]** 또는 ESC → 메인 메뉴로 언제든 그만둘 수 있고, 다 끝나면 자동으로 메인 메뉴로 돌아갑니다
- 튜토리얼에서는 포인트 · 도전 과제가 쌓이지 않습니다
- 새 튜토리얼을 아직 해 보지 않았다면 메인 메뉴의 **튜토리얼 버튼이 금빛으로 반짝이고 「NEW」**가 붙습니다
