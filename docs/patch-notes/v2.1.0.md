# Soul Saver 2.1.0 패치노트 — 캐릭터 밸런스 · 킹 슬라임 결계 완화

## ⚔️ 검사 (크게 상향)

- 체력 150 → **180**
- 공격력 3 → **3.6**, 공격 속도 0.4 → **0.5**, 베기 사거리 5 → **5.5**
- 회전 베기 피해 2~6배 → **3~8배**

## 🗡️ 도적 (초반 상향 · 후반 하향)

- 체력 70 → **85**, 공격력 0.85 → **1**
- 필살기 충전이 빨라졌습니다 (약 43초 → **34초**)
- 출혈 돌진 베기 1.5배 → **2.2배**, 출혈 1.2 → **1.5**
- 후반 성장 스킬 하향
  - 던지기 연습: 중첩당 5~14% → **4~10%**
  - 출혈 폭발: 남은 출혈의 100~190% → **80~140%**
  - 넘치는 기세: 표창 8~20개 → **6~15개**
  - 그림자 매듭: 나눠 받는 피해 20~50% → **15~36%**

## 🔫 거너 (상향)

- 공격력 **1.15배**
- 장전 시간 1.8초 → **1.3초**

## 🏹 궁수 (생존 상향)

- 체력 65 → **80**
- 필살기 충전이 빨라졌습니다 (약 43초 → **37초**)

## ⚗️ 연금술사 (소폭 하향)

- 플라스크 피해 1.6배 → **1.45배**

## ✨ 고유 스킬

- 고유 스킬 피해가 캐릭터의 공격력 배율 대신 **공통 기준**으로 계산됩니다.
  느린 평타를 보상하려고 높게 잡은 공격력 배율 때문에 캐릭터마다 고유 스킬 위력이 크게 달랐던 것을 맞췄습니다.
- 캐릭터 화면과 도감의 "스킬 게이지 150%"를 **"필살기 충전 67%"**로 바꿨습니다. (높을수록 빨리 찹니다)

## 👑 보스 필살기 「결계 침식」

- 보스 필살기 게이지가 **약한 공격에도 더 잘 찹니다.** (평타 기준 약 1.5배, 센 한 방은 그대로)
- 킹 슬라임 「산성 범람」을 피하기 쉽게 고쳤습니다.
  - 튕기는 산성 덩어리 최대 8개 → **5개**, 더 느리고 뜸하게
  - 산성 비 5곳 → **3곳**, 예고 1초 → **1.3초**
  - 줄무늬 간헐천: 한 줄 건너 한 줄 → **세 줄에 한 줄**, 4초마다, 예고 **1.5초**
