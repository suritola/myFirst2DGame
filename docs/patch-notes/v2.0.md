# 민근이의 첫번째 게임 v2.0 패치노트

zip을 풀고 `MyFirstGame.exe`를 실행하세요. v1.2 · v1.3의 변경 내용도 모두 들어 있습니다.

## 🆕 3장 · 초원

- 지옥의 군주를 쓰러뜨리면 성문 너머 **초원**이 열립니다. 들어가면 특수 능력 포인트 +2.
- **새 적 5종**: 초원 슬라임 · 거대 벌 · 버섯 괴물 · 회색 늑대 · 나무 정령
  - 스킬: 산성 웅덩이 · 꽃가루 구름(감속) · 버섯 지뢰 · 울부짖음(주변 적 가속) · 뿌리 가시 행렬
- **보스 킹 슬라임**: 대점프 · 산성 비 · 구르기 돌진, 체력 절반 아래에서 3연속 점프
  - 쓰러질 때마다 **1마리 → 2마리 → 3마리**로 분열하는 3페이즈 보스
- 초원 타일셋과 소품(돌 아치 문, 전나무, 통나무, 꽃, 버섯, 가로등, 건초 등)을 새로 그렸습니다.

## 🎨 도트 이펙트

- 폭발 · 영혼 폭발 · 충격파 · 번개 · 베기 · 레이저 · 운석 · 화염 회오리 · 룬 마법진 · 가시 등 **도트 이펙트 18종**을 그렸습니다.
- 무기 · 액티브 스킬 · 패시브 · 적 · 보스 스킬 모두 도트 이펙트를 사용합니다.

## ⚔️ 적 · 보스 스킬 전면 교체

- 투사체를 없애고 적마다 **서로 다른 새 스킬**을 씁니다.
  - 구울 도약 강타, 망령 영혼 순간이동, 임프 **X자 레이저**, 불꽃 해골 자폭, 지옥견 돌진, 용암 골렘 **3연속 지면 파동**, 악마 기사 **회전 베기**
- 리치 왕: **망령의 손아귀**, **뼈 가시 격자**, 망자의 의식은 **회전 레이저**로 변경
- 1장의 첫 적(해골)은 스킬을 쓰지 않습니다.

## 🎯 무기별 필살기 (우클릭)

들고 있는 무기마다 **전혀 다른 형식**의 필살기가 나갑니다.

| 무기 | 필살기 |
|---|---|
| 지옥불 산탄총 | 지옥불 포격 — 거대한 부채꼴 폭발 3연발 |
| 영혼 저격총 | 관통 레일건 — 화면을 가로지르는 굵은 광선 |
| 저주받은 쌍권총 | 총알 폭풍 — 나선형 사방 난사 |
| 화염 방사기 | 화염 회오리 — 적을 빨아들이는 불기둥 |
| 영혼 인도 지팡이 | 영혼 떼 — 구슬 다섯이 번갈아 돌진 |
| 번개 사슬총 | 뇌운 — 번개가 연달아 떨어짐 |
| 부메랑 낫 | 죽음의 춤 — 적 사이를 순간이동하며 벰 |
| 용암 유탄 발사기 | 용암 융단폭격 — 줄지어 떨어지는 운석 |

## 🛒 상점 · 성장

- **떠돌이 상점**: `P`로 열던 상점이 사라지고, 일반 몹 10마리마다 나타나는 **상점 제단**에 10초 안에 다가가야 열립니다.
- **스킬 타겟 수** 강화 추가 (6 → 최대 12)
- **스킬 게이지**가 시간으로 차고, 적을 처치하면 잠깐 빨라집니다 (적중으로는 차지 않아 난사 방지).
- 흡혈 스킬을 **코인 자석**(주변 코인 끌어오기)으로 교체하고, 처치 시 회복 능력을 없앴습니다.
- 특수 무기 강화 가격 약 5배

## 🗺️ 맵

- 1장 · 2장의 부딪히는 지형지물을 모두 없애고 **통과할 수 있는 장식**만 남겼습니다.
- 보스를 뺀 적은 최대 20마리까지만 나옵니다.
