# Soul Saver 1.8.7 패치노트 — v1.8.3 ~ v1.8.7 합침

## 📦 v1.8.7 — 게임 커서 · 더 선명한 도트 · 30% 더 어렵게

### 🖱️ 게임 커서

- 윈도우 기본 포인터 대신 **게임 전용 커서**를 씁니다.
  - 메뉴 · 레벨업 · 영혼 트리 · 일시정지 화면: **화살표**
  - 전투 중: **조준점**
- 크게(48픽셀) 그리고 검은 테두리 두 겹과 밝은 테두리를 둘러, 어두운 지옥 맵에서도 밝은 초원에서도 또렷하게 보입니다.
- **설정 → 게임 → 게임 커서**에서 끄면 윈도우 기본 포인터로 돌아갑니다.

### 🛍️ 커서 스킨 (스킨 상점 → 커서)

| 등급 | 이름 | 모습 |
|---|---|---|
| 일반 | 뼈 커서 | 빛바랜 뼛빛 |
| 희귀 | 불씨 커서 | 타오르는 주황빛 |
| 영웅 | 영혼 커서 | 보랏빛 영혼 · 푸른 빛 |
| 전설 | 황금 커서 | 황금빛 · 둘레를 도는 별빛 반짝임 |

### 👁️ 더 잘 보이는 도트

- 적과 보스에 **짙은 윤곽선**을 둘러 배경과 섞이지 않게 했습니다.
- 플레이어에는 **밝은 윤곽선**을 둘러 적 무리 속에서도 바로 찾을 수 있습니다.
- **중간 보스 이름표**를 크게 키우고 어두운 판 · 금빛 테두리를 깔았습니다. 살짝 숨 쉬듯 커졌다 작아지며, 전투 이펙트보다 위에 보입니다.

### ⚔️ 난이도 30% 상향

- 모든 난이도(무한 모드 포함)에서 **적 · 보스 체력 +30%**, **적이 주는 피해 +30%**.
- 적이 나오는 빈도와 이동 속도는 그대로입니다.

### 🌐 번역

- 영혼 트리 가지 이름 중 **생존 · 영혼 · 재물**이 영어 · 일본어 · 중국어에서도 한국어로 나오던 문제를 고쳤습니다.

## 📦 v1.8.6 — 새 도전 과제 6개

무기 진화 · 영혼 트리 · 스킨 상점에 맞춘 스팀 도전 과제를 더했습니다. 이제 도전 과제는 모두 **32개**입니다.

### 🏆 새 도전 과제

| 이름 | 조건 |
|---|---|
| **새로운 무기** | 무기를 처음 진화시켰다 |
| **뿌리 내리기** | 한 판에서 영혼 트리 칸 20개를 배웠다 |
| **세계수** | 한 판에서 영혼 트리 칸 40개를 배웠다 |
| **운명 비틀기** | 레벨업 카드를 다시 뽑았다 |
| **새 옷** | 스킨 상점에서 스킨을 처음 샀다 |
| **전설의 풍모** | 전설 등급 스킨을 샀다 |

- 이미 스킨을 산 적이 있다면 다음 실행 때 **새 옷 · 전설의 풍모**가 바로 풀립니다.

### 🔁 조건이 바뀐 도전 과제

액티브 스킬과 특수 무기가 없어지면서 풀 수 없게 된 도전 과제 둘을 지금 성장 방식에 맞게 바꿨습니다.

- **손이 모자라 → 운명을 쥐다**: 스킬 칸 3개 채우기 → 한 판에서 **운명** 가지 칸 3개 배우기
- **무기고 → 완성된 무기**: 특수 무기 2개 들기 → 한 판에서 **무기를 두 번 진화**
- **진화**: 설명을 "능력을 처음 진화시켰다"로 바꿨습니다 (영혼 트리 패시브 진화 · 거너 무기 2차 진화).

### 🔧 참고

- 이번 버전은 스팀에 올렸습니다.

## 📦 v1.8.4 — 무기에 맞게 실시간으로 바뀌는 트리 · 레벨업 카드

지금 든 무기(진화 형태)에 **쓸모없는 레벨업 카드와 영혼 트리 칸은 나오지 않습니다.** 무기가 진화하면 그 자리에서 바로 바뀝니다.

### 🃏 레벨업 카드 (거너 전용 카드)

| 지금 무기 | 나오지 않는 카드 | 이유 |
|---|---|---|
| 영혼 저격총 | 유도 탄두 | 곧게 뚫고 나가는 저격 |
| 화염 방사기 | 도탄 · 폭발 탄두 · 유도 탄두 · 소각탄 · 장전 충격파 | 불길 판정 · 이미 불태움 · 탄창 없음 |
| 산탄총 · 용암 유탄 발사기 | 도탄 · 유도 탄두 | 날아가는 총알이 없음 |
| 추적탄(영혼 인도 지팡이) | 유도 탄두 | 이미 유도됨 |
| 부메랑 낫 | 도탄 · 유도 탄두 · 장전 충격파 | 되돌아오는 낫 · 탄창 없음 |
| 번개 사슬총 | 전기탄 | 이미 번개 |

- 진화 전에 고른 카드가 새 무기에 안 맞게 되면 버려지지 않고, **그 카드의 단계마다 무기 피해 +6%**로 자동으로 바뀝니다. 카드 설명에도 표시됩니다.

### 🌳 영혼 트리

- 무기에 안 맞는 칸은 **숨겨집니다.**
  - **탄창 · 장전**: 탄창이 없는 무기(화염 방사기 · 부메랑 낫)
  - **고속탄**: 날아가는 총알이 없거나 판정이 다른 무기(산탄총 · 유탄 · 화염 · 낫)
  - **철갑탄(관통)**: 이미 다 뚫는 무기(저격총 · 화염 · 낫 · 궁수 투창)나 총알이 없는 무기
  - **노려보는 눈빛(조준 감속)**: 조준하지 않는 필살기(산탄총 · 쌍권총 · 유탄)
  - **넓은 베기(검사)**: 베기 폭이 형태로 정해지는 전쟁 망치 · 채찍검 · 기창
- 이미 배운 칸은 사라지지 않고 "지금 무기에는 효과가 없습니다"라고 표시됩니다.
- **치명타 · 처형**이 거너의 산탄총 · 용암 유탄 발사기에도 들어가도록 판정을 넓혔습니다. 모든 무기에서 의미가 있습니다.

### 🔧 참고

- 이번 버전도 GitHub 릴리즈로만 배포하고 스팀에는 올리지 않았습니다.

## 📦 v1.8.3 — 스킨 상점

캐릭터를 다 사고 나면 포인트가 계속 남던 문제를 위해, 메인 메뉴에 **스킨 상점**을 열었습니다.
스킨은 **겉모습과 소리만** 바꿉니다. 몸 크기 · 판정 · 투사체 크기는 그대로이고, 효과는 옅고 작게 해서 적의 붉은 경고를 가리지 않습니다.

### 🛍️ 스킨 상점 (메인 메뉴 → 스킨 상점)

- 종류 탭(**캐릭터 · 무기 · 이펙트**) → 캐릭터 고르기(해금한 캐릭터만) → 스킨 카드
- 카드마다 등급 색 테두리와 **움직이는 미리보기**(캐릭터는 달리는 모습), 가격 · 보유 · 장착 상태가 나옵니다. 전설 카드는 금빛 테두리가 은은하게 빛납니다.
- 아래 설명줄에서 **소리 듣기**로 바뀌는 소리를 미리 들을 수 있습니다.
- 비싼 물건이라 **구매는 두 번 눌러야** 됩니다 (처음 누르면 "한 번 더 누르면 구매"). 산 스킨은 바로 장착되고, **기본**을 누르면 원래대로 돌아갑니다.
- 캐릭터 고르기 화면의 초상화도 장착한 스킨으로 보입니다.

### 🗡️ 무기 스킨 10종 (캐릭터마다 희귀 · 영웅)
