# Soul Saver 2.0.3 패치노트 — 보스 필살기 「결계」

## 🌑 보스 필살기 · 결계 전개

- 모든 보스에게 **필살기 게이지**가 생겼습니다. 보스를 때릴 때마다 차오르며, **약한 공격을 여러 번 하는 것보다 센 한 방이 훨씬 많이 채웁니다.** (보스 체력바 바로 아래 보라색 줄)
- 게이지가 가득 차면 게임이 멈추고 카메라가 보스에게 다가간 뒤, 화면 가운데에서 보스가 결계의 이름을 외칩니다.
- **맵 전체가 어두워지고 보스 둘레에 둥근 결계가 펼쳐져** 9초 동안 그 안에 갇힙니다. 결계 안에서는 보스마다 다른 공격이 쏟아집니다. 모두 경고가 먼저 보이니, 피할 수는 있습니다.
  - 리치 왕 「망자의 묘역」: 천천히 도는 영혼 광선 넷, 틈이 있는 저주 고리, 발밑에서 솟는 뼈 가시
  - 지옥의 군주 「연옥 낙화」: 쏟아지는 운석, 틈이 있는 화염 고리, 결계를 가로지르는 용암 줄기
  - 킹 슬라임 「산성 범람」: 결계 벽에 튕기는 산성 덩어리, 산성 비, 한 줄씩 번갈아 솟는 간헐천
- 결계 전용 배경음악과 외침 · 전개 · 파열 효과음이 새로 생겼습니다.
- 갈라진 킹 슬라임들은 게이지를 함께 쓰며, 한 번에 하나만 결계를 펼칩니다.

## ⬆ 레벨업 방식

- 경험치가 차면 **레벨업 포인트만 쌓이고, 레벨은 카드를 골라야 오릅니다.** 건너뛰기를 하면 레벨이 그대로라, 최대 레벨 안에서 원하는 카드를 더 고를 수 있습니다.

## 🔧 그 밖에

- 보스를 쓰러뜨리면 **화면의 잡몹이 영혼이 되어 흩어지고, 그 스테이지에서는 더 나오지 않습니다.** (무한 모드는 화면만 정리)
- 3장 초원 배경음악을 무겁고 웅장한 곡으로 바꿨습니다.
- ESC 메뉴의 「메인 메뉴로」를 누르면 한 번 더 확인합니다.
- 도적 그림자 숙련 4단계(돌진 뒤 3초 안에 한 번 더 돌진)가 **무기 진화 뒤에 작동하지 않던 문제**를 고쳤습니다.
