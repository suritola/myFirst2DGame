# Gun Saver v1.0 패치노트

첫 공개 빌드입니다. zip을 풀고 `MyFirstGame.exe`를 실행하세요.

## 🆕 새 콘텐츠

- **2장 · 불타는 지옥**: 리치 왕을 쓰러뜨리면 신전 문이 열리고, 들어가면 지옥 스테이지로 넘어갑니다.
  - 새 적 5종 (임프 · 불꽃 해골 · 지옥견 · 용암 골렘 · 악마 기사)과 보스 **지옥의 군주**
- **특수 능력 20종**: 지옥 입장 때 스킬 트리에서 포인트 3개로 무기 · 스킬 · 패시브 중 3개를 고릅니다.
  - 무기는 `Q`로 교체, 스킬은 `E` · `F` · `Space`
- **중간 보스**: 2장에서 적 단계가 오를 때마다 거대한 중간 보스가 나옵니다. 잡으면 특수 능력 포인트를 줍니다.
- **특수 강화 · 진화**: 포인트로 새 능력을 배우거나, 가진 능력을 **진화**시킵니다. 진화 효과는 20종 모두 다릅니다.
  - 화면 아래 반짝이는 버튼 또는 `T`
- **무기 강화 상점**: 2장부터 상점에서 특수 무기마다 피해 · 속도 · 특성을 강화합니다.
- **레벨업 능력 추가**: 생명의 샘 (초당 체력 회복) · 피의 굶주림 (처치 시 체력 회복)

## 🎨 그래픽 · UI

- 게임 분위기에 맞춰 UI 전체를 새로 만들었습니다.
- 플레이어 · 적 · 보스 · 코인 · 힐팩 그림을 교체했습니다.
- 맵을 다시 배치하고, 보스는 신전 문에서 등장합니다.
- 새 HUD:
  - 획득한 능력 아이콘과 레벨
  - 적 머리 위 체력바
  - 여닫을 수 있는 능력치 창
  - 특수 능력 칸 (쿨타임 · 무기 상태)
- 능력과 스킬 게이지에 마우스를 올리면 현재 효과가 보입니다.
- 스킬 조준 표시를 룬 문양으로 바꾸고, 보스 전용 사망 연출을 추가했습니다.

## 🔊 조작감 · 피드백

- 특수 능력 모두에 소리, 조준 미리보기, 알림 글자를 넣었습니다.
  - 저격총 충전음과 긴 조준선
  - 산탄총 부채꼴 범위
  - 유탄 낙하 지점 표시
  - 화염 방사기 불꽃 입자
- 대시 · 장판 · 갈고리는 키를 누르고 있으면 미리보기가 나오고, 떼면 발동합니다.
- 쏘는 방향을 바라보고, 적끼리 겹치지 않고 서로 밀어냅니다.

## ⚖️ 밸런스

- 성장 속도, 적 체력 · 피해, 상점 가격을 전반적으로 조정했습니다.
- 적이 단계별로 여러 종류가 섞여서 더 많이, 더 빨리 나옵니다.
- 멀티샷은 발사 수가 늘수록 한 발당 피해가 줄어듭니다.
- 2장 적을 강화했습니다.
- 지옥불 산탄총은 멀티샷과 겹치지 않도록 근거리 즉발 폭발로 바꿨습니다.

## 🐛 버그 수정

- 시작하자마자 플레이어가 위로 밀려나던 문제
- 적과 부딪혀도 피해가 들어가지 않던 문제
- 게임 안에서 한글 몇 글자가 깨지던 문제
- 빌드가 실패하던 문제
- 시작 시 적 생성기 에러가 나던 문제
- 스킬 탄이 스킬 게이지를 채우던 문제
