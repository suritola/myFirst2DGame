# Soul Saver 1.8.5 패치노트 — 한눈에 보이는 메인 화면

메인 화면 버튼 일곱 개가 세로로 길게 늘어서 있어 읽기 어려웠던 것을 새로 정리했습니다.

## 🏠 메인 화면

- **게임 시작**은 크게 따로, 재생 아이콘과 함께 가운데에 둡니다. 난이도 줄은 바로 위에 그대로 있습니다.
- 나머지 메뉴는 그 아래에 **아이콘 칸 3 × 2**로 모았습니다.
  - 캐릭터 · 스킨 상점 · 도감
  - 튜토리얼 · 설정 · 종료 (종료는 붉은 빛으로 구분)
- 메뉴마다 새로 그린 도트 아이콘을 붙였습니다.
- 오른쪽 위에 **보유 포인트**를 코인 아이콘과 함께 늘 보여 줍니다. 스킨을 사면 바로 줄어듭니다.
