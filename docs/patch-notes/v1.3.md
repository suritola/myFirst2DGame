# Gun Saver v1.3 패치노트

> 이 버전은 빌드 없이 기록만 남깁니다. 변경 내용은 v2.0 빌드에 모두 들어 있어요.

## 🆕 새 기능

- **신전 문 강제 입장**: 리치 왕을 잡고 30초가 지나면 문으로 끌려가 자동으로 들어갑니다.
- **무기별 스탯 분리**: 특수 무기마다 탄창 · 연사 · 장전 시간을 따로 가집니다. `R`은 들고 있는 무기만 장전합니다.
  - 무기 강화에 **탄창 +25%**를 추가했습니다.
- **무기별 우클릭 스킬**: 타겟팅 스킬이 들고 있는 무기에 따라 달라집니다.
- **특수 능력 창 분리**: 무기(기본 권총 포함) · 스킬 · 패시브 세 창으로 나눴습니다.
- **레벨업 카드**: 클릭으로 고르고 `Space`로 확정합니다.

## 🎨 연출

- 리치 왕 특수 스킬을 **망자의 의식**으로 개편했습니다 (룬 고리, 영혼 등불, 대폭발).
- 적 · 보스 경고 표시, 투사체, 폭발, 무기 · 스킬 이펙트를 화려하게 바꿨습니다.
- 부메랑 낫을 진짜 낫 모양으로 바꿨습니다.

## ⚖️ 밸런스

- 지옥 맵 지형지물을 최소화했습니다.
- 스킬 게이지를 화염 방사기 기준으로 낮췄습니다. 쌍권총 게이지는 더 낮췄습니다.
- 흡혈 스킬 회복량 1 → 0.4.
- 체력 물약 드랍률을 절반으로 줄였습니다.

## 🐛 버그 수정

- 기본 권총을 들고 있는지 표시되지 않던 문제
- 진화할 때 글자가 겹치던 문제
- 타겟팅 스킬 자동 연사 중에 직접 사격이 되던 문제
