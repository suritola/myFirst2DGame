# Gun Saver v2.3 패치노트

## 📖 도감

- 메인 메뉴에 **도감** 버튼을 추가했습니다.
- 탭 8개: **적 · 보스 · 무기 · 스킬 · 패시브 · 진화 · 레벨업 · 상점**
  - 적과 보스는 체력 · 속도 · 접촉 피해와 쓰는 스킬을 보여줍니다.
  - 무기마다 필살기 이름과 방식(즉발 / 조준), 강화 특성을 보여줍니다.
- 한국어 · English · 日本語 · 中文 모두 지원합니다.

## 🔫 필살기

- **죽음의 춤 (부메랑 낫)**: 카메라가 움직이는 범위의 가운데에 고정되고, 플레이어는 적들 사이를 오가며 벤 뒤 제자리로 돌아옵니다.
- **화염 회오리 · 관통 레일건**: 다시 우클릭을 꾹 눌러 위치 · 방향을 조준합니다.

## 🐛 버그 수정

- 게임을 시작할 때 능력치 패널에서 오류가 나던 문제
- 한국어로 설정했을 때 설정 창의 日本語 · 中文 버튼 글자가 깨지던 문제
- 보스 체력바에 보스 이름 대신 "좀 쎈 보스"가 나오던 문제 (리치 왕 · 지옥의 군주 · 킹 슬라임)
