# Soul Saver 2.1.3 패치노트 — v2.0.9 ~ v2.1.3 합침

## 📦 v2.1.3 — 스킬 이펙트 강화 · 연금술사 하향 · 패치노트 버튼

### ✨ 스킬 이펙트가 확 눈에 띕니다

- 필살기 · 특수 능력 · 고유 스킬 · 영혼 트리 효과의 이펙트가 **더 밝고 진하게** 보입니다
- 장식 이펙트는 **1.25배 크게** (공격 범위를 나타내는 이펙트는 실제 범위 그대로)
- 스킬 이펙트가 **적과 적 이펙트 위에** 그려지고, 터질 때 **밝은 빛이 번집니다**
- 평타 · 적 공격 · 처치 연출은 그대로라서 스킬이 쓰이는 순간이 또렷하게 구분됩니다

### ⚗️ 연금술사 (하향)

- 한 방에 적 무리를 지워 버려서 너무 셌습니다
- 플라스크 피해 1.45배 → **1.2배**
- 불안정 플라스크 1.8배 → **1.6배**
- 화상 피해 35% → **30%**
- 폭발 범위 1.8 → **1.65**
- 공격 속도 0.8 → **0.75**

### 📜 메인 메뉴 「패치노트」 버튼

- 메인 화면 오른쪽 위(보유 포인트 아래)에 **패치노트** 버튼이 생겼습니다
- 지난 버전까지 왼쪽 목록에서 골라 볼 수 있습니다 (최신이 맨 위)
- 게임을 켤 때 이번 버전 패치노트가 뜨는 것은 그대로입니다

## 📦 v2.1.2 — 장 순서 변경 · 캐릭터 밸런스

### 🗺️ 장 순서가 바뀌었습니다

- **1장 초원(킹 슬라임) → 2장 지하 묘역(리치 왕) → 3장 불타는 지옥(지옥의 군주) → 4장 영혼의 심연(거울의 군주)**
- 바뀐 자리에 맞춰 세기를 다시 맞췄습니다. 각 장은 **그 자리(몇 번째 장)의 원래 세기**입니다.
  - **1장 초원**: 예전 1장 정도로 약해짐 — 킹 슬라임 체력 합계 약 480, 보스까지 60마리
  - **2장 지하 묘역**: 예전 2장 정도로 강해짐 — 리치 왕 체력 2400, 보스까지 80마리
  - **3장 불타는 지옥**: 예전 3장 정도로 — 지옥의 군주 체력 5950
  - 적 체력 · 적이 주는 피해(몸통 · 스킬 · 보스 · 결계) · 처치 보상을 함께 맞췄습니다
- 캐릭터마다 시작 이야기가 초원에서 시작하도록 바뀌었습니다
- 중간 보스와 특수 강화는 전처럼 2장부터, 첫 장을 끝내면 특수 능력 선택
- 무한 모드 · 일일 도전 · 체험판은 예전 그대로입니다

### ⚖️ 캐릭터 밸런스

**🔫 거너 (하향 · 초반에 너무 강했음)**
- 공격력 1.15배 → **1.05배**
- 장전 시간 1.3초 → **1.5초**

**⚔️ 검사 (상향)**
- 체력 180 → **200**, 공격력 3.6 → **4**
- 공격 속도 0.5 → **0.55**
- 필살기가 더 빨리 찹니다

**🏹 궁수 (상향)**
- 체력 80 → **95**, 공격력 1.1 → **1.25**
- 공격 속도 0.9 → **1**
- 필살기가 더 빨리 찹니다

**🗡️ 도적**
- 변경 없음

## 📦 v2.1.1 — 4장 영혼의 심연 · 일일 도전 · 판 기록

### 🌑 새 장: 4장 「영혼의 심연」

- 킹 슬라임을 쓰러뜨리면 엔딩 대신 **갈라진 땅 아래로 심연의 문**이 열립니다. 이제 진짜 마지막 장입니다.
- 검푸른 심연 맵, 떠다니는 영혼 불빛, 새 배경음악
- 새 적 5종
  - **떠도는 혼**: 흔들리며 다가오다 빠르게 돌진
  - **사슬 망령**: 사슬을 던져 맞으면 앞까지 끌어당김
  - **공허 눈알**: 부채꼴 사이를 광선으로 훑음
  - **영혼 수확자**: 둘레를 두 번 베어 냄 (두 번째는 바깥 고리라 안쪽이 안전)
  - **심연 거상**: 세 갈래로 땅을 갈라 가시를 솟게 함
- 들어갈 때 특수 능력 포인트 +2 (거너는 보스 처치 때 무기 진화)

### 🪞 마지막 보스: 거울의 군주

- **내 캐릭터의 평타를 흉내 냅니다** — 거너는 연사, 검사는 돌진 베기, 도적은 표창 부채, 궁수는 관통 화살, 연금술사는 플라스크
- **분신술**: 셋 중 진짜만 피해를 받습니다
- **십자 낙인**: 곁으로 순간이동한 뒤 십자 광선
- 체력 절반 아래 특수 **「되비친 기억」**: 이번 판에 **내가 가장 많이 쓴 공격**(평타 · 필살기 · 고유 스킬 · 영혼 트리 · 특수 능력)을 거꾸로 돌려줍니다
- 결계 **「거울의 방」**: 둘레의 거울들이 한 쌍씩 나를 노려 광선을 쏘고, 깨진 거울 조각이 쏟아집니다
- 엔딩 이야기도 새로 바뀌었습니다

### 📅 일일 도전 (새 모드)

- 메인 메뉴의 **「일일 도전」** 칸 (무한 모드가 열리면 시작할 수 있음)
- 하루(UTC)마다 **오늘의 영웅 1명 + 오늘의 규칙 1개**가 정해지고, 무한 모드 규칙으로 얼마나 버티는지 겨룹니다
  - 규칙 7가지: 몰려드는 무리 · 강철 피부 · 질풍 · 거인의 시간 · 유리 몸 · 분노한 주문 · 풍요 (하나는 불리하고 하나는 보상)
  - 아직 사지 않은 캐릭터도 그날 영웅이면 빌려 씁니다
- 몇 번이든 다시 도전할 수 있고 가장 좋은 기록만 남습니다

### 🏆 스팀 순위표

- **오늘의 순위**(일일 도전)와 **무한 모드 순위**(최고 생존 시간)
- 일일 도전 창에서 1~10위와 내 순위를 볼 수 있고, 결과 화면에 내 순위가 뜹니다

### 📊 이번 판 기록

- 결과 화면 오른쪽에 **준 피해**(평타 · 필살기 · 특수 능력별 · 고유 스킬 · 영혼 트리)와 **받은 피해**(적 · 적 스킬 · 보스 스킬 · 결계) 막대
- 쓰러졌을 때 **어디서 무엇에 쓰러졌는지** 표시
- ESC 메뉴 요약에 준 피해 비율 상위 4개

### 🏅 업적 2개 추가

- **심연으로** — 영혼의 심연에 발을 들였다
- **거울을 깨뜨리다** — 거울의 군주가 결계를 펼치기 전에 쓰러뜨렸다
- 「Soul Saver」(게임 클리어)는 이제 거울의 군주를 쓰러뜨려야 얻습니다

### 🔧 그 밖에

- 무한 모드에 4장 적과 거울의 군주도 나옵니다
- 내부 코드 정리 (동작 변화 없음)

## 📦 v2.1.0 — 캐릭터 밸런스 · 킹 슬라임 결계 완화

### ⚔️ 검사 (크게 상향)

- 체력 150 → **180**
- 공격력 3 → **3.6**, 공격 속도 0.4 → **0.5**, 베기 사거리 5 → **5.5**
- 회전 베기 피해 2~6배 → **3~8배**

### 🗡️ 도적 (초반 상향 · 후반 하향)

- 체력 70 → **85**, 공격력 0.85 → **1**
- 필살기 충전이 빨라졌습니다 (약 43초 → **34초**)
- 출혈 돌진 베기 1.5배 → **2.2배**, 출혈 1.2 → **1.5**
- 후반 성장 스킬 하향
  - 던지기 연습: 중첩당 5~14% → **4~10%**
  - 출혈 폭발: 남은 출혈의 100~190% → **80~140%**
  - 넘치는 기세: 표창 8~20개 → **6~15개**
  - 그림자 매듭: 나눠 받는 피해 20~50% → **15~36%**

### 🔫 거너 (상향)

- 공격력 **1.15배**
- 장전 시간 1.8초 → **1.3초**

### 🏹 궁수 (생존 상향)

- 체력 65 → **80**
- 필살기 충전이 빨라졌습니다 (약 43초 → **37초**)

### ⚗️ 연금술사 (소폭 하향)

- 플라스크 피해 1.6배 → **1.45배**

### ✨ 고유 스킬

- 고유 스킬 피해가 캐릭터의 공격력 배율 대신 **공통 기준**으로 계산됩니다.
  느린 평타를 보상하려고 높게 잡은 공격력 배율 때문에 캐릭터마다 고유 스킬 위력이 크게 달랐던 것을 맞췄습니다.
- 캐릭터 화면과 도감의 "스킬 게이지 150%"를 **"필살기 충전 67%"**로 바꿨습니다. (높을수록 빨리 찹니다)

### 👑 보스 필살기 「결계 침식」

- 보스 필살기 게이지가 **약한 공격에도 더 잘 찹니다.** (평타 기준 약 1.5배, 센 한 방은 그대로)
- 킹 슬라임 「산성 범람」을 피하기 쉽게 고쳤습니다.
  - 튕기는 산성 덩어리 최대 8개 → **5개**, 더 느리고 뜸하게
  - 산성 비 5곳 → **3곳**, 예고 1초 → **1.3초**
  - 줄무늬 간헐천: 한 줄 건너 한 줄 → **세 줄에 한 줄**, 4초마다, 예고 **1.5초**

## 📦 v2.0.9 — 결계 시작 피해 수정 · 게임 안 패치노트

### 🌑 보스 필살기 「결계 침식」

- 보스가 결계를 펼치자마자 **내 체력이 한꺼번에 크게 닳던 문제**를 고쳤습니다.
  외침 연출로 멈췄던 화면이 풀리는 순간, 옆에 있던 잡몹 · 날아오던 탄 · 보스 몸통에 한꺼번에 맞던 것이 원인이었습니다.
- 결계가 펼쳐지기 시작해서 다 펼쳐진 뒤 잠깐까지 **2초 동안 무적**입니다.

### 📜 게임 안 패치노트

- 게임을 켤 때마다 메인 메뉴에 **이번 버전의 패치노트**가 뜹니다.
- 휠로 내려 읽고, [닫기] 또는 ESC로 닫습니다. 게임을 하고 메인 메뉴로 돌아올 때는 다시 뜨지 않습니다.
