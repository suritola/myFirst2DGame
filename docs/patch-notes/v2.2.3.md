# Soul Saver 2.2.3 패치노트 — 유도 탄두 방식 변경

## 🔫 거너 「유도 탄두」 — 스치면 보정

- 총알이 날아가는 내내 적 쪽으로 휘던 방식이 원하는 적을 맞히기 어렵고 불편해서 **방식을 바꿨습니다**
- 이제 총알은 **조준한 대로 곧게** 날아갑니다
- 날아가는 길 **바로 옆을 스치는 적**이 있으면, 그 적 쪽으로만 빠르게 꺾여 맞습니다 (앞쪽 5칸 안에서만)
  - 멀리서부터 미리 꺾지 않아서 노린 적을 놓치거나 옆의 적에게 끌려가지 않습니다
  - 적을 지나쳤으면 다시 곧게 날아갑니다
- 단계마다 **보정 범위**가 넓어집니다: 0.9 → 1.3 → 1.7칸
- 꺾일 때만 보랏빛 꼬리가 보입니다
