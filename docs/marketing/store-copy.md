# 상점 문구 개편안 (첫인상 중심)

기존 글(`docs/steam/store-page.md`)은 내용이 충실하지만 **첫 줄이 세계관**으로 시작해서, 검색 결과나 추천 목록에서 몇 초 만에 "어떤 게임인지"가 안 보입니다.
여기서는 사람들이 가장 먼저 보는 세 곳만 바꿉니다. 나머지 본문은 그대로 써도 됩니다.

1. **짧은 설명**: 상점 상단, 캡슐 옆에 뜨는 글 (최대 300자)
2. **상세 설명 맨 위 첫 문단**: 기존 본문 위에 붙이기
3. **태그 순서**: 상위 태그가 추천 노출을 좌우

적용 위치: Steamworks → 앱 관리 → 상점 페이지 편집 → 언어별 탭

---

## 3. 태그 (위에서부터 중요한 순)

스팀은 **상위 태그**를 보고 비슷한 게임을 좋아하는 사람에게 추천합니다. 서바이버류 팬에게 노출되도록 순서를 바꿉니다.

| 순서 | 태그 | 이유 |
|---|---|---|
| 1 | **Action Roguelike** | 핵심 장르 |
| 2 | **Bullet Hell** | 서바이버류 대부분이 다는 태그 |
| 3 | **Top-Down Shooter** | 시점 · 조작 |
| 4 | **Pixel Graphics** | 그림체로 찾는 사람이 많음 |
| 5 | **Roguelite** | |
| 6 | **Dark Fantasy** | 분위기 |
| 7 | **2D** · **Singleplayer** · **Survival** · **Difficult** | 나머지 |

- Steamworks 태그 목록에 **"Survivorlike"** 또는 **"Bullet Heaven"** 같은 서바이버류 전용 태그가 있으면 **1~2위**에 넣으세요. 이 장르 팬이 가장 많이 찾는 태그입니다. 목록에 있는지는 태그 편집 화면에서 확인해야 합니다.
- 비교 대상으로 자주 언급될 게임: *Vampire Survivors*, *20 Minutes Till Dawn*, *Brotato*. 상점 글에 직접 이름을 쓰지는 말고, 커뮤니티 홍보에서 "~를 좋아한다면"으로 활용합니다.
