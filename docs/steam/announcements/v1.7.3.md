## English

**Title:** 1.7.3 Update — Level Up On Your Terms, Balance Pass 2

```
[h2]⬆️ Level-up points[/h2]
Leveling up no longer pops a window mid-fight. Points are stored — press [Space] to pick abilities whenever you like.

[h2]⏱️ Play time[/h2]
Play time is now clearly shown at the top of the screen.

[h2]⚖️ Balance[/h2]
[list]
[*]Special abilities are now equally strong on every character
[*]Lower mid-boss health, Swordsman Spin Slash adjusted
[*]Pickpocket and Hunter's Momentum adjusted
[/list]

※ The executable is now Soul Saver.exe. Your old save data is moved over automatically.
```

## 简体中文

**标题：** 1.7.3 更新 — 随时选择的升级，第二轮平衡调整

```
[h2]⬆️ 升级点数[/h2]
升级后不再立刻弹出窗口，而是积攒点数。随时按 [Space] 选择能力。

[h2]⏱️ 游戏时间[/h2]
屏幕顶部清晰显示游戏时间。

[h2]⚖️ 平衡调整[/h2]
[list]
[*]特殊能力强度不再受角色影响，各角色一致
[*]降低精英首领血量，调整剑士回旋斩
[*]调整扒窃和狩猎气势
[/list]

※ 可执行文件更名为 Soul Saver.exe，旧存档会自动迁移。
```
