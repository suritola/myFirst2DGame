## 한국어

**제목:** v3.9 업데이트 — 무기별 장전 소리, 설명 통일, 더 잘 보이는 적 스킬

```
[h2]🔊 무기마다 다른 장전 소리[/h2]
산탄총 펌프, 저격총 노리쇠, 카드 섞기, 폭죽 심지까지 — 캐릭터 · 무기마다 장전 소리가 다릅니다.

[h2]📋 설명 형식 통일[/h2]
모든 레벨업 카드가 「한 문장 + 수치 지금 → 다음 + Lv」 모양으로, 모든 특수 능력이 「본문 + 진화」 모양으로 바뀌었습니다.

[h2]⚔️ 몸 박치기[/h2]
일반 적과 부딪혀도 적이 죽지 않고 튕겨 나갑니다. 맞은 뒤 무적 시간은 0.6초입니다.

[h2]👁️ 적 스킬이 더 잘 보이게[/h2]
스킬을 쓰는 적 머리 위에 스킬 이름이 뜨고, 경고 표시가 어떤 바닥에서도 잘 보이게 바뀌었습니다.

[h2]✨ 특수 능력 선택 창[/h2]
고른 능력에 금빛 테두리와 순서 번호가 붙습니다.
```

## English

**Title:** v3.9 Update — Unique Reload Sounds, Unified Descriptions, Clearer Enemy Skills

```
[h2]🔊 Every weapon reloads differently[/h2]
Shotgun pumps, sniper bolts, card shuffles, firework fuses — each character and weapon has its own reload sound.

[h2]📋 Unified descriptions[/h2]
Every level-up card now reads "one sentence + stat now → next + Lv", and every special ability reads "effect + Evolve".

[h2]⚔️ Body contact[/h2]
Regular enemies no longer die when they touch you; they bounce off instead. Invincibility after a hit is now 0.6s.

[h2]👁️ Clearer enemy skills[/h2]
Enemies show the name of the skill they're casting, and warning markers now stand out on every floor.

[h2]✨ Ability picker[/h2]
Picked abilities get a glowing gold frame and a pick-order number.
```

## 日本語

**タイトル:** v3.9 アップデート — 武器ごとのリロード音、説明の統一、見やすい敵スキル

```
[h2]🔊 武器ごとに違うリロード音[/h2]
ショットガンのポンプ、スナイパーのボルト、カードのシャッフル、花火の導火線まで — キャラクター・武器ごとにリロード音が違います。

[h2]📋 説明の形式を統一[/h2]
すべてのレベルアップカードが「一文 + 数値 現在 → 次 + Lv」、すべての特殊能力が「本文 + 進化」の形になりました。

[h2]⚔️ 体当たり[/h2]
通常の敵とぶつかっても敵は死なず、弾き返されます。被弾後の無敵時間は0.6秒です。

[h2]👁️ 敵スキルが見やすく[/h2]
スキルを使う敵の頭上にスキル名が表示され、警告表示がどんな床でも見やすくなりました。

[h2]✨ 特殊能力選択画面[/h2]
選んだ能力に金色の縁取りと選択順の番号が付きます。
```

## 简体中文

**标题：** v3.9 更新 — 专属装填音效、描述统一、敌人技能更醒目

```
[h2]🔊 每把武器的装填声都不同[/h2]
霰弹枪泵动、狙击枪拉栓、洗牌、烟花引信 — 每个角色和武器都有专属装填音效。

[h2]📋 描述格式统一[/h2]
所有升级卡牌统一为「一句说明 + 数值 当前 → 下一级 + Lv」，所有特殊能力统一为「效果 + 进化」。

[h2]⚔️ 身体碰撞[/h2]
普通敌人碰到你时不再死亡，而是被弹开。受击后无敌时间为0.6秒。

[h2]👁️ 敌人技能更醒目[/h2]
施放技能的敌人头顶会显示技能名称，警告标记在任何地面上都清晰可见。

[h2]✨ 特殊能力选择界面[/h2]
已选能力带有金色边框和选择顺序编号。
```
