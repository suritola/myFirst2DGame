## English

**Title:** v3.8 Update — Icon HUD, 4 Passives per Character, Endless Rework

```
[h2]🖥️ At-a-glance HUD[/h2]
Weapons, skills and passives are now icon tiles showing cooldowns, ammo, stacks and status. Hover for full details. Panels can be collapsed, and play time is shown on every difficulty.

[h2]🧙 Four passives per character[/h2]
The Swordsman, Rogue, Archer and Alchemist each get two new passives.

[h2]🃏 Level-up cards[/h2]
[list]
[*]Two new character cards each
[*]Endlessly stackable cards like Heart of Steel now have a max level — no more 1000+ HP
[/list]

[h2]♾️ Endless[/h2]
Start at level 10. Weak enemies come first, and stronger ones join over time.

[h2]👹 Mid-bosses[/h2]
Now marked with a name tag and a glowing outline.
```

## 简体中文

**标题：** v3.8 更新 — 图标 HUD、每个角色4个被动、无尽模式重做

```
[h2]🖥️ 一目了然的 HUD[/h2]
武器、技能、被动改为图标格，显示冷却、弹匣、叠层和状态，鼠标悬停可查看详细说明。面板可以折叠，所有难度都会显示游戏时间。

[*]每个角色新增2张专属卡牌

[/list]

[h2]♾️ 无尽模式[/h2]
从10级开始，先出现弱小的敌人，强敌逐渐加入。

现在带有名牌和发光轮廓，一眼就能认出。
```
