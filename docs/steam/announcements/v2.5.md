## English

**Title:** v2.5 Update — Settings Overhaul, Key Rebinding, 10 New Achievements

```
[h2]⚙️ Bigger Settings[/h2]
Settings are now split into [b]General · Display · Controls[/b] tabs.
[list]
[*][b]General[/b]: separate [b]Music and Sound Effects volume[/b] on top of master volume.
[*][b]Display[/b]: fullscreen / windowed, resolution, VSync, [b]turn off screen shake[/b], [b]turn off flash effects[/b]
[*][b]Controls[/b]: [b]rebind[/b] move, reload, weapon swap, skills 1–3, interact and special upgrade. The tutorial and on-screen hints follow your keys.
[/list]

[h2]⌨️ Skill 3 is now on C[/h2]
The default key for the third skill changed from [b]Space → C[/b]. Space is now only for opening the shop and confirming level-ups.
Prefer the old layout? Set Skill 3 back to Space in Settings → Controls.

[h2]⏸️ Pausing[/h2]
[list]
[*]You can press ESC while aiming an ultimate. (Aim is cancelled, gauge is kept.)
[*]The game pauses automatically when the window loses focus (Alt+Tab, etc.).
[/list]

[h2]🏆 10 New Achievements (20 total)[/h2]
Get Back Up · Regular Customer · All Hands · Arsenal · Final Form · Ultimate Addict · Veteran · Legendary Hunter · Flawless Duel · Close Call

[h2]🐛 Fixes & Improvements[/h2]
[list]
[*]"Restart" in the pause menu no longer stutters
[*]Skill aim markers no longer linger after pausing mid-aim
[*]Better performance with many enemies on screen
[/list]
```
