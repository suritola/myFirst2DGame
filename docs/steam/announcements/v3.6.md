## English

**Title:** v3.6 Update — Rogue's Hunter's Momentum · Ability Picker Fixes

```
[h2]🗡️ New Rogue level-up card: Hunter's Momentum[/h2]
Every kill fills your right-click skill gauge. It fills more as the card levels up and your attack grows, so late in a run you can dash almost nonstop.

[h2]🏹 Archer aim line[/h2]
Shown only while drawing, as a dotted line that reaches the edge of the screen.

[h2]🐛 Special ability picker fixes[/h2]
[list]
[*]"Can evolve" only showed on some abilities
[*]Abilities evolved even without the "Can evolve" label
[*]A different ability than the one clicked could get selected
[*]Hard to tell what was selected — picks are now larger with a gold frame and a "Selected" badge
[/list]
```
