## 한국어

**제목:** v3.1 업데이트 — 캐릭터별 이야기 · 검사 베기 · 도적 출혈 돌진

```
[h2]📖 캐릭터마다 다른 이야기[/h2]
고른 캐릭터에 따라 시작 이야기와 엔딩 이야기가 달라집니다. 떠돌이 기사, 보물을 노린 도적, 숲의 사냥꾼, 미친 학자의 모험을 만나 보세요!

[h2]⚔️ 검사: 장검으로 직접 베기[/h2]
[list]
[*]평타가 검기 대신 [b]장검을 크게 휘둘러 앞쪽 부채꼴의 적을 직접 베는[/b] 공격으로 바뀌었습니다 (사거리 약 12칸)
[*]위→아래, 아래→위로 번갈아 휘두르며, 새 베기 이펙트가 나옵니다
[*]특수 무기 대검의 범위도 넓어졌습니다
[/list]

[h2]🗡️ 도적: 출혈 돌진[/h2]
우클릭이 은신 대신 [b]출혈 돌진[/b]으로 바뀌었습니다. 무적 상태로 마우스 방향으로 돌진해, 지나간 적을 베고 4초 동안 출혈 피해를 입힙니다.

[h2]🔋 스킬 게이지[/h2]
캐릭터 스킬 게이지 %는 이제 [b]높을수록 늦게 차는[/b] 수치로 바르게 적용됩니다. (도적 150% → 거너보다 1.5배 늦게)
```

## English

**Title:** v3.1 Update — Character Stories · Swordsman Slashes · Rogue Bleeding Dash

```
[h2]📖 A Story for Every Character[/h2]
The opening and ending stories now change depending on your character. Meet the wandering knight, the treasure-hunting rogue, the forest hunter and the mad scholar!

[h2]⚔️ Swordsman: Real Sword Swings[/h2]
[list]
[*]Basic attacks no longer fire sword waves: the Swordsman [b]swings the longsword wide and cuts every enemy in a cone ahead[/b] (range ~12)
[*]Swings alternate up and down with a brand-new slash effect
[*]The Greatsword special weapon now has a wider reach
[/list]

[h2]🗡️ Rogue: Bleeding Dash[/h2]
The right-click skill is now [b]Bleeding Dash[/b] instead of Stealth. Dash toward the mouse while invincible, cutting every enemy you pass and making them bleed for 4 seconds.

[h2]🔋 Skill Gauge[/h2]
A character's skill gauge % now correctly means [b]higher = fills slower[/b]. (Rogue 150% → fills 1.5× slower than the Gunner)
```

## 日本語

**タイトル:** v3.1 アップデート — キャラクター別ストーリー・剣士の斬撃・盗賊の出血突進

```
[h2]📖 キャラクターごとの物語[/h2]
選んだキャラクターによって、オープニングとエンディングの物語が変わります。流浪の騎士、宝を狙う盗賊、森の狩人、狂った学者の冒険をお楽しみください！

[h2]⚔️ 剣士：長剣で直接斬る[/h2]
[list]
[*]通常攻撃が剣気ではなく、[b]長剣を大きく振るい前方の扇形の敵を直接斬る[/b]攻撃になりました（射程 約12）
[*]上→下、下→上と交互に振り、新しい斬撃エフェクトが出ます
[*]特殊武器「大剣」の範囲も広がりました
[/list]

[h2]🗡️ 盗賊：出血突進[/h2]
右クリックが隠密から[b]出血突進[/b]に変わりました。無敵状態でマウスの方向へ突進し、通り過ぎた敵を斬って4秒間出血ダメージを与えます。

[h2]🔋 スキルゲージ[/h2]
キャラクターのスキルゲージ%は[b]高いほど遅く溜まる[/b]数値として正しく適用されるようになりました。（盗賊150% → ガンナーより1.5倍遅い）
```

## 简体中文

**标题:** v3.1 更新 — 角色专属剧情 · 剑士斩击 · 盗贼出血突进

```
[h2]📖 每位角色的专属故事[/h2]
开场与结局剧情会根据所选角色而不同。来见证流浪骑士、觊觎宝藏的盗贼、森林猎人和疯狂学者的冒险吧！

[h2]⚔️ 剑士：长剑直接斩击[/h2]
[list]
[*]普通攻击不再发出剑气，而是[b]大幅挥舞长剑，直接斩击前方扇形范围内的敌人[/b]（射程约12）
[*]上下交替挥砍，并带有全新的斩击特效
[*]特殊武器"大剑"的范围也扩大了
[/list]

[h2]🗡️ 盗贼：出血突进[/h2]
右键技能由隐身改为[b]出血突进[/b]。在无敌状态下朝鼠标方向突进，斩击途经的敌人并使其流血4秒。

[h2]🔋 技能能量[/h2]
角色的技能能量%现在正确表示[b]越高积累越慢[/b]。（盗贼150% → 比枪手慢1.5倍）
```
