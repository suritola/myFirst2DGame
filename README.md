## 📖 소개

사방에서 적이 몰려드는 **지하 묘역**에서 살아남아 리치 왕을 쓰러뜨리면, 신전 문 너머 **불타는 지옥**이 열립니다.
적을 처치해 경험치와 코인을 모으고, **레벨업 능력** · **상점 강화** · **특수 능력**으로 캐릭터를 키워
두 스테이지의 보스를 모두 쓰러뜨리세요.

## ✨ 주요 특징

| | |
|---|---|
| 🔫 **리볼버 사격** | 마우스로 조준하는 8연발 사격. 탄창이 비면 자동 재장전 |
| 🎯 **타겟팅 스킬** | 게이지가 가득 차면 시간이 느려지며 주변 적을 차례로 조준 → 한꺼번에 일제 사격 |
| 🗺️ **두 개의 스테이지** | 1장 지하 묘역(3단계) → 신전 문 → 2장 불타는 지옥(5단계) |
| 👑 **보스전** | 부하를 계속 불러내는 보스 **리치 왕**과 **지옥의 군주** |
| 🌳 **특수 능력 스킬 트리** | 지옥 입장 시 무기·스킬·패시브 20종 중 하나를 선택 |
| 🃏 **레벨업 능력** | 레벨업마다 3개의 능력 중 하나를 선택하는 로그라이크식 성장 |
| 🛒 **상점 강화** | 모은 코인으로 공격력·공격 속도·재장전·탄창·이동 속도 업그레이드 |

## 🎮 조작법

| 입력 | 동작 |
|:---:|---|
| `W` `A` `S` `D` / 방향키 | 이동 |
| 🖱️ 좌클릭 | 마우스 방향으로 사격 (쏘는 동안 그쪽을 바라봄) |
| 🖱️ 우클릭 (누르고 있기) | 타겟팅 스킬 — 떼면 조준한 적에게 일제 사격 |
| `R` | 재장전 |
| `Q` | 특수 무기 ↔ 기본 권총 교체 (특수 능력이 무기일 때) |
| `E` / `Space` | 특수 스킬 사용 (특수 능력이 스킬일 때) |
| `P` | 상점 열기 |
| `ESC` | 일시정지 메뉴 / 상점 닫기 |

## 🖥️ 화면 구성

- **왼쪽 위**: 체력 · 스킬 게이지, 그 아래 획득한 레벨업 능력 아이콘 (마우스를 올리면 현재 효과 표시)
- **오른쪽 위**: 코인 · 점수
- **오른쪽 아래**: 탄약, 특수 능력 칸(쿨타임·교체 상태), 화살표로 여닫는 능력치 창 (공격력·방어력·공격 속도·재장전·이동 속도)
- **아래**: 레벨 · 경험치 바
- **적 머리 위**: 체력바 (초록 → 주황 → 빨강)

## ⚔️ 게임 시스템

### 1장 · 지하 묘역

| 적 | 체력 | 접촉 피해 | 처치 보상 |
|---|:---:|:---:|---|
| 💀 해골 | 3 | 5 | 경험치 20 · 코인 1 |
| 🧟 구울 | 8 | 8 | 경험치 30 · 코인 2 |
| 👻 망령 | 16 | 12 | 경험치 45 · 코인 3 |
| 👑 리치 왕 | 800 | 25 | 경험치 200 · 코인 50 |

| 단계 | 조건 | 등장 비율 (해골 : 구울 : 망령) |
|:---:|---|---|
| 1 | 시작 | 100 : 0 : 0 |
| 2 | 20마리 처치 | 45 : 55 : 0 |
| 3 | 40마리 처치 | 25 : 35 : 40 |
| 👑 | 60마리 처치 | 신전 문에서 리치 왕 등장 |

리치 왕을 쓰러뜨리면 **신전 문에 포탈이 열리고**, 들어가면 특수 능력을 고른 뒤 2장으로 넘어갑니다.
레벨·능력·코인·상점 강화는 그대로 유지됩니다.

### 2장 · 불타는 지옥

| 적 | 체력 | 접촉 피해 | 특징 |
|---|:---:|:---:|---|
| 😈 임프 | 6 | 7 | 지그재그로 다가옴 |
| 🔥 불꽃 해골 | 12 | 9 | |
| 🐺 지옥견 | 14 | 10 | 3초마다 돌진 |
| 🪨 용암 골렘 | 45 | 16 | 느리지만 넉백을 거의 받지 않음 |
| ⚔️ 악마 기사 | 32 | 18 | 넉백 저항, 5초마다 돌진 |
| 👑 지옥의 군주 | 2200 | 35 | 4초마다 부하 4마리 (체력 절반 이하: 2.5초마다 5마리) |

| 단계 | 조건 | 등장 비율 (임프 : 해골 : 지옥견 : 골렘 : 기사) |
|:---:|---|---|
| 1 | 시작 | 100 : 0 : 0 : 0 : 0 |
| 2 | 15마리 처치 | 50 : 50 : 0 : 0 : 0 |
| 3 | 30마리 처치 | 30 : 35 : 35 : 0 : 0 |
| 4 | 45마리 처치 | 20 : 25 : 25 : 30 : 0 |
| 5 | 60마리 처치 | 15 : 20 : 20 : 20 : 25 |
| 👑 | 80마리 처치 | 성문에서 지옥의 군주 등장 |

> 적은 플레이어에게 닿으면 자폭하며 피해를 주고, 맞은 뒤 0.8초 동안은 무적입니다.

### 🌳 특수 능력 (지옥의 문)

<img src="docs/images/skill-tree.png" alt="특수 능력 스킬 트리" width="760">

뿌리에서 뻗은 세 갈래 중 **하나를 골라** 지옥에서 사용합니다. 노드에 마우스를 올리면 설명을 볼 수 있어요.

<details>
<summary>🔫 무기 8종 — <code>Q</code>로 기본 권총과 교체</summary>

| 능력 | 효과 |
|---|---|
| 지옥불 산탄총 | 총알 없이 앞쪽 부채꼴(60°, 6칸) 안의 적 모두에게 즉시 250% + 강한 넉백, 발사 간격 1.4배 |
| 영혼 저격총 | 누르고 있다 떼면 발사, 모든 적 관통, 충전에 따라 150~300% |
| 저주받은 쌍권총 | 누르고 연사, 발사 간격 절반, 발당 55%, 탄 절반 소모 |
| 화염 방사기 | 불을 뿜어 관통 + 화상, 탄약 대신 과열 게이지 |
| 영혼 인도 지팡이 | 가장 가까운 적을 쫓는 유도탄, 발당 70% |
| 번개 사슬총 | 맞은 적에서 최대 4마리에게 번개 연쇄 (튈 때마다 −20%) |
| 부메랑 낫 | 날아갔다 돌아오며 모두 벰, 150%, 한 번에 하나 |
| 용암 유탄 발사기 | 마우스 위치에서 폭발 200% + 용암 웅덩이, 탄 2개 |

</details>

| 영혼 폭발 | 처치로 모은 영혼(5개 이상)을 터뜨려 주변 피해 | 5초 |

### 🃏 레벨업 능력

<details>
<summary>능력 10종 펼쳐보기</summary>

| 능력 | 효과 |
|---|---|
| 관통하는 총알 | 총알 관통력 증가 |
| 코인충 | 코인 획득량 증가 |
| 재활용 에너지 | 스킬 게이지 요구량 20% 감소 (최소 10) |
| 노려보는 눈빛 | 스킬 사용 중 시간이 더 느리게 흐름 |
| 더 많은 경험치 | 처치 경험치 +10% |
| 흡혈 스킬 | 스킬로 맞춘 적 1명당 체력 2 회복 |
| 멀티 샷 | 한 번에 발사하는 총알 +1 (발당 피해 100% → 70% → 55% → 45% → 40%) |
| 밀어내기 | 넉백 효과 +25% (최대 3번) |
| 강철같은 심장 | 체력 완전 회복 + 최대 체력 20% 증가 |
| 단단한 신체 | 받는 피해 30% 감소 (최대 2번) |

</details>

### 🛒 상점

`P` 키로 열 수 있으며 코인으로 다섯 가지 능력치를 영구 강화합니다.
강화할 때마다 가격이 올라가고, 각 능력치에는 최대치가 있습니다.

`공격력` · `공격 속도 (초당 5발까지)` · `재장전 속도 (0.8초까지)` · `탄창 크기 (16발까지)` · `이동 속도 (6번까지)`

## 🚀 실행 방법

1. **Unity Hub**에서 `Unity 2022.3.28f1` 설치
2. 이 저장소를 클론
   ```bash
   git clone https://github.com/suritola/myFirst2DGame.git
   ```
3. Unity Hub → **Add project from disk** → 클론한 폴더 선택
4. `Assets/Prefabs/Scenes/MainMenu.unity` 씬을 열고 ▶ 재생

> 💡 2장을 빨리 확인하려면 `Enemy_Spawner` → Stages → 동굴 → **Boss Kills**를 1로 낮춰 보세요.

## 📁 프로젝트 구조

```
Assets/
├── Animation/            # 플레이어·적·보스 애니메이션 (Hell/ = 지옥 적)
├── Prefabs/
│   ├── Scenes/           # MainMenu → GameScene → GameOver
│   ├── Hell/             # 지옥 적 5종 + 지옥의 군주
│   └── *.prefab          # 동굴 적, 리치 왕, 총알, 코인, 힐팩
├── Scripts/              # 게임 로직 (C#)
│   ├── PlayerController.cs   # 이동·사격·타겟팅 스킬·피격
│   ├── EnemySpawn.cs         # 스테이지별 적 생성과 페이즈·보스 진행
│   ├── StageConfig.cs        # 스테이지·페이즈 설정 데이터
│   ├── StageManager.cs       # 보스 처치 → 포탈 → 특수 능력 → 지옥 전환
│   ├── SpecialAbilities.cs   # 특수 능력 20종 (무기·스킬·패시브)
│   ├── SpecialTreeUI.cs      # 특수 능력 스킬 트리 화면
│   ├── LevelShop.cs          # 레벨업 능력 선택
│   ├── Shop.cs               # 코인 상점
│   └── *HUD.cs, Tooltip*.cs  # HUD·툴팁
├── Sounds/               # 효과음
├── Sprites/              # 캐릭터·타일셋·UI 스프라이트 (UI/Theme = 직접 만든 UI 키트)
└── Tiles/                # 타일 팔레트
```
