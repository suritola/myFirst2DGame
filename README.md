## 📖 소개

사방에서 적이 몰려드는 **지하 묘역**에서 살아남아 리치 왕을 쓰러뜨리면, 신전 문 너머 **불타는 지옥**이 열립니다.
적을 처치해 경험치와 코인을 모으고, **레벨업 능력** · **상점 강화** · **특수 능력**으로 캐릭터를 키워
두 스테이지의 보스를 모두 쓰러뜨리세요.

## ✨ 주요 특징

| | |
|---|---|
| 🔫 **리볼버 사격** | 마우스로 조준하는 8연발 사격. 탄창이 비면 자동 재장전 |
| 🎯 **타겟팅 스킬** | 게이지가 가득 차면 시간이 느려지며 주변 적을 차례로 조준 → 한꺼번에 일제 사격 |
| 🗺️ **두 개의 스테이지** | 1장 지하 묘역(3단계) → 신전 문 → 2장 불타는 지옥(5단계, 요새 · 용암 호수 · 기둥 숲 구조물) |
| ⚠️ **피할 수 있는 스킬** | 모든 적이 스킬을 하나씩 쓰고, 보스는 스킬 3개 + 체력 절반 이하 특수 스킬. 전부 경고 표시 후 발동 |
| 👑 **보스전** | 부하를 계속 불러내는 보스 **리치 왕**과 **지옥의 군주** |
| 🌳 **특수 능력 스킬 트리** | 지옥 입장 시 포인트 3개로 무기·스킬·패시브 20종 중 3개를 선택 |
| 🧬 **중간 보스 · 진화** | 2장에서 단계가 오를 때마다 중간 보스 등장 → 처치하면 특수 능력 포인트로 새 능력을 배우거나 가진 능력을 진화 |
| 🃏 **레벨업 능력** | 레벨업마다 3개의 능력 중 하나를 선택하는 로그라이크식 성장 |
| 🛒 **상점 강화** | 모은 코인으로 공격력·공격 속도·재장전·탄창·이동 속도 업그레이드, 2장부터는 특수 무기별 강화 |

## 🎮 조작법

| 입력 | 동작 |
|:---:|---|
| `W` `A` `S` `D` / 방향키 | 이동 |
| 🖱️ 좌클릭 | 마우스 방향으로 사격 (쏘는 동안 그쪽을 바라봄) |
| 🖱️ 우클릭 (누르고 있기) | 타겟팅 스킬 — 떼면 조준한 적에게 일제 사격 |
| `R` | 재장전 |
| `Q` | 무기 교체: 기본 권총 → 특수 무기1 → 특수 무기2 … |
| `E` / `F` / `Space` | 특수 스킬 1 / 2 / 3 (고른 순서대로 배정) — 대시·장판·갈고리는 누르고 있으면 미리보기, 떼면 발동 |
| `P` | 상점 열기 |
| `T` | 특수 강화 (특수 능력 포인트가 있을 때) |
| `ESC` | 일시정지 메뉴 / 상점 닫기 |

## 🖥️ 화면 구성

- **왼쪽 위**: 체력 · 스킬 게이지, 그 아래 획득한 레벨업 능력 아이콘 (마우스를 올리면 현재 효과 표시)
- **오른쪽 위**: 코인 · 점수
- **오른쪽 아래**: 탄약, 화살표로 여닫는 능력치 창 (공격력·방어력·공격 속도·재장전·이동 속도)
- **왼쪽 아래**: 특수 능력 칸 (고른 능력마다 한 줄, 쿨타임·교체 상태)
- **아래**: 레벨 · 경험치 바, 특수 능력 포인트가 있으면 그 위에 반짝이는 **특수 강화** 버튼
- **적 머리 위**: 체력바 (초록 → 주황 → 빨강)

#### 👑 보스 스킬

보스는 스킬 3개를 번갈아 쓰고, **체력이 절반 아래로 떨어지면 특수 스킬**을 추가로 씁니다. 모두 경고(원 · 선 · 고리)가 먼저 보이니 움직여서 피하세요.

| 보스 | 스킬 | 특수 스킬 (체력 50% 미만) |
|---|---|---|
| 👑 리치 왕 | **영혼 탄막** 사방으로 두 번 퍼지는 영혼탄 · **저주 표식** 플레이어 주변 5곳 폭발 · **뼈 창** 세 갈래 조준선 뒤 빠른 뼈 창 | **죽음의 소용돌이** 5초간 회전하는 세 줄기 영혼탄 |
| 👑 지옥의 군주 | **화염 돌진** 굵은 경로 표시 뒤 돌진 · **운석 낙하** 주변에 차례로 떨어지는 운석 7개 · **화염 파동** 틈이 셋 있는 불의 고리 | **십자 불길** 천천히 도는 네 줄기 불기둥 5초 |

#### 🧬 중간 보스

2장에서는 **단계가 오를 때마다**(15 · 30 · 45 · 60마리) 그 단계에 나오는 적 중 하나가 **중간 보스**로 등장합니다.
몸이 1.8배 크고 주황빛이며, 체력 12배 · 접촉 피해 1.5배에 넉백을 거의 받지 않고 **닿아도 자폭하지 않아요**.
쓰러뜨리면 경험치 8배, 코인 뭉치, 힐팩과 함께 **특수 능력 포인트 1개**를 얻습니다.

### 🌳 특수 능력 (지옥의 문)

<img src="docs/images/skill-tree.png" alt="특수 능력 스킬 트리" width="760">

**포인트 3개**로 세 갈래에서 **능력 3개를 골라** 지옥에서 사용합니다. 노드를 누르면 선택, 다시 누르면 취소되고, 마우스를 올리면 설명을 볼 수 있어요.
무기를 여러 개 고르면 `Q`로 돌아가며 바꾸고, 스킬은 고른 순서대로 `E` · `F` · `Space`에 배정됩니다.

#### ⬆️ 특수 강화와 진화

중간 보스에게서 얻은 **특수 능력 포인트**는 화면 아래 반짝이는 **특수 강화** 버튼(또는 `T`)으로 씁니다. 같은 스킬 트리가 열리고:

- **새 능력**을 누르면 배웁니다 (스킬은 `E` · `F` · `Space` 세 칸까지).
- 파란 테두리의 **이미 가진 능력**을 누르면 **진화**합니다. 능력마다 한 번, HUD에서 이름 뒤에 `+`가 붙어요.
- 포인트는 원하는 만큼만 쓰고 **닫기**로 아껴 둘 수 있습니다.

#### 🔔 능력별 피드백

모든 특수 능력은 **소리 · 미리보기 · 알림 글자**로 상태를 알려줍니다.

- **조준 미리보기**: 저격총은 조준 방향으로 길게 뻗는 점선 조준선, 산탄총은 공격 범위 부채꼴, 유탄은 떨어질 지점의 폭발 범위, 유도 지팡이는 쫓아갈 적에게 표적 고리가 표시됩니다.
- **저격총 충전**: 누르고 있으면 총구의 빛이 커지며 청록 → 금색으로 바뀌고, 점점 높아지는 충전음 뒤 완충 시 "띵" 소리와 함께 조준선이 금색으로 반짝입니다.
- **조준형 스킬**(그림자 대시 · 지옥불 장판 · 피의 갈고리): 키를 누르고 있으면 도착 지점 · 장판 범위 · 갈고리가 걸릴 적이 보이고, 떼면 발동합니다.
- **화염 방사기**: 불꽃 입자가 노랑 → 주황 → 빨강 → 연기로 변하며 퍼지고 불티가 튑니다. 점화음과 불길 소리, 불붙은 적 몸의 불꽃, 과열 시 연기로 상태를 알 수 있어요.
- **상태 알림**: 과열 / 냉각 완료, 영혼 부족 · 영혼 폭발 준비, 저주탄 장전, 가시 반격, 불사 발동 등을 캐릭터 위 글자와 소리로 알려줍니다.
- **쿨타임**: 쿨타임 중에 누르면 경고음과 남은 시간이, 다시 쓸 수 있게 되면 알림음과 함께 HUD 줄이 반짝입니다.
- **지속 효과**: 시간 왜곡은 주변에 파란 고리, 희생의 계약은 붉은 기운이 지속 시간 동안 표시됩니다.

### 🛒 상점

`P` 키로 열 수 있으며 코인으로 다섯 가지 능력치를 영구 강화합니다.
강화할 때마다 가격이 올라가고, 각 능력치에는 최대치가 있습니다.

한 번에 확 강해지지 않도록 **조금씩 자주** 오르는 방식입니다.

| 강화 | 한 번에 | 한계 |
|---|---|---|
| 공격력 | +0.25 (가격 ×1.3) | 없음 |
| 공격 속도 | 발사 간격 −6% | 초당 약 4.5발 |
| 재장전 속도 | −0.12초 | 0.9초 |
| 탄창 크기 | +1발 | 14발 |
| 이동 속도 | +4% | 5번 |

힐팩은 체력을 15 회복합니다.

#### 🔧 무기 강화 (2장부터)

2장에서 특수 무기를 가지고 있으면 상점 오른쪽 위에 **무기 강화** 탭이 생깁니다. 무기마다 따로 세 가지를 강화해요.

| 강화 | 한 단계 효과 | 최대 | 가격 |
|---|---|:---:|---|
| 피해 | +15% | 5 | 15코인부터 ×1.5 |
| 속도 | 발사 간격 −10% (낫은 더 빨리 날아감) | 5 | 15코인부터 ×1.5 |
| 특성 | 산탄총 사거리 +1 · 저격총 충전 −15% · 쌍권총/지팡이 관통 +1 · 화염 열 발생 −20% · 사슬 연쇄 +1 · 낫 크기 +15% · 유탄 범위 +0.6 | 3 | 30코인부터 ×1.8 |

## 🚀 실행 방법

### 빌드 받아서 플레이

윈도우 빌드는 비공개 저장소 [myFirst2DGame-builds](https://github.com/suritola/myFirst2DGame-builds/releases)의 Releases에 버전별로 올라갑니다. 초대받은 사람만 받을 수 있어요. zip을 풀고 `MyFirstGame.exe`를 실행하면 됩니다.

### 에디터에서 실행

1. **Unity Hub**에서 `Unity 2022.3.28f1` 설치
2. 이 저장소를 클론
   ```bash
   git clone https://github.com/suritola/myFirst2DGame.git
   ```
3. Unity Hub → **Add project from disk** → 클론한 폴더 선택
4. `Assets/Prefabs/Scenes/MainMenu.unity` 씬을 열고 ▶ 재생

> 💡 2장을 빨리 확인하려면 `Enemy_Spawner` → Stages → 동굴 → **Boss Kills**를 1로 낮춰 보세요.
