## 📖 소개

사방에서 적이 몰려드는 지하 묘역에서 살아남는 것이 목표입니다.
적을 처치해 경험치와 코인을 모으고, **레벨업 능력**과 **상점 강화**로 캐릭터를 키워
점점 강해지는 적들과 마지막에 등장하는 **보스**를 쓰러뜨리세요.

## ✨ 주요 특징

| | |
|---|---|
| 🔫 **리볼버 사격** | 마우스로 조준하는 6연발 사격. 탄창이 비면 자동 재장전 |
| 🎯 **타겟팅 스킬** | 게이지가 가득 차면 시간이 느려지며 주변 적을 차례로 조준 → 한꺼번에 일제 사격 |
| 📈 **3단계 페이즈** | 처치 수에 따라 적이 점점 강해지는 페이즈 진행 |
| 👑 **보스전** | 공격받을 때마다 부하를 소환하는 보스 **"좀 쎈 보스"** 등장 |
| 🃏 **레벨업 능력** | 레벨업마다 3개의 능력 중 하나를 선택하는 로그라이크식 성장 |
| 🛒 **상점 강화** | 모은 코인으로 공격력·공격 속도·재장전·탄창·이동 속도 업그레이드 |

## 🎮 조작법

| 입력 | 동작 |
|:---:|---|
| `W` `A` `S` `D` / 방향키 | 이동 |
| 🖱️ 좌클릭 | 마우스 방향으로 사격 |
| 🖱️ 우클릭 (누르고 있기) | 타겟팅 스킬 — 떼면 조준한 적에게 일제 사격 |
| `R` | 재장전 |
| `P` | 상점 열기 |
| `ESC` | 일시정지 메뉴 / 상점 닫기 |

## ⚔️ 게임 시스템

### 페이즈 & 보스

| 적 | 체력 | 접촉 피해 | 처치 보상 |
|---|:---:|:---:|---|
| 💀 해골 | 3 | 5 | 경험치 20 · 코인 1 |
| 🧟 구울 | 8 | 8 | 경험치 30 · 코인 2 |
| 👻 망령 | 16 | 12 | 경험치 45 · 코인 3 |
| 👑 리치 왕 | 800 | 25 | 경험치 200 · 코인 50 |

| 단계 | 조건 | 등장 비율 (해골 : 구울 : 망령) |
|:---:|---|---|
| 1 | 시작 | 100 : 0 : 0 |
| 2 | 20마리 처치 | 45 : 55 : 0 |
| 3 | 40마리 처치 | 25 : 35 : 40 |
| 👑 | 60마리 처치 | 신전 문에서 리치 왕 등장 |

> 보스는 5초마다(체력 절반 이하에서는 3초마다) 부하를 소환합니다. 적은 플레이어에게 닿으면 자폭하며 피해를 주고, 맞은 뒤 0.8초 동안은 무적이에요.

### 레벨업 능력

<details>
<summary>능력 10종 펼쳐보기</summary>

| 능력 | 효과 |
|---|---|
| 관통하는 총알 | 총알 관통력 증가 |
| 코인충 | 코인 획득량 증가 |
| 재활용 에너지 | 스킬 게이지 요구량 20% 감소 (최소 10) |
| 노려보는 눈빛 | 스킬로 조준한 적의 이동 속도 20% 감소 |
| 더 많은 경험치 | 처치 경험치 +10% |
| 흡혈 스킬 | 스킬로 맞춘 적 1명당 체력 회복 |
| 멀티 샷 | 한 번에 발사하는 총알 +1 (발당 피해 100% → 70% → 55% → 45% → 40%) |
| 밀어내기 | 넉백 효과 +60% |
| 강철같은 심장 | 체력 완전 회복 + 최대 체력 20% 증가 |
| 단단한 신체 | 받는 피해 30% 감소 (최대 2번) |

</details>

### 상점

`P` 키로 열 수 있으며 코인으로 다섯 가지 능력치를 영구 강화합니다.
강화할 때마다 가격이 올라가니 어떤 능력치에 투자할지 잘 선택하세요.

`공격력` · `공격 속도` · `재장전 속도` · `탄창 크기` · `이동 속도`

## 🚀 실행 방법

1. **Unity Hub**에서 `Unity 2022.3.28f1` 설치
2. 이 저장소를 클론
   ```bash
   git clone https://github.com/suritola/myFirst2DGame.git
   ```
3. Unity Hub → **Add project from disk** → 클론한 폴더 선택
4. `Assets/Prefabs/Scenes/MainMenu.unity` 씬을 열고 ▶ 재생

## 📁 프로젝트 구조

```
Assets/
├── Animation/        # 플레이어·적·보스 애니메이션
├── Prefabs/
│   ├── Scenes/       # MainMenu → GameScene → GameOver
│   └── *.prefab      # 적, 보스, 총알, 코인, 힐팩
├── Scripts/          # 게임 로직 (C#)
│   ├── PlayerController.cs   # 이동·사격·스킬·피격
│   ├── EnemySpawn.cs         # 적 생성과 페이즈·보스 진행
│   ├── LevelShop.cs          # 레벨업 능력 선택
│   └── Shop.cs               # 코인 상점
├── Sounds/           # 효과음
├── Sprites/          # 캐릭터·타일셋·UI 스프라이트
└── Tiles/            # 타일 팔레트
```
